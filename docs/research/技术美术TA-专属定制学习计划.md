## 三、图形学主线（GAMES101 理论 + tinyrenderer 实战）

> 22 讲 + 8 作业，是你渲染向 TA 的**命根子**。策略：**视频 1.5–2 倍速看 + 讲义精读 + 作业必做**，每讲沉淀 1 条 KB `note`。

| 讲次区间 | 主题 | 作业（必做，作品集来源） |
|---|---|---|
| 1–4 | 变换：模型/视图/投影、齐次坐标、旋转 | **作业 1–2：软光栅化器（MVP + 三角形光栅化 + 深度测试）** |
| 5–8 | 光栅化、抗锯齿、深度、着色（Blinn-Phong） | **作业 3：着色（Phong/法线/凹凸贴图）** |
| 9–12 | 纹理映射、几何（曲线/曲面/网格） | **作业 4–5：贝塞尔曲线 + 几何** |
| 13–16 | 光线追踪：Whitted、BVH、加速结构 | **作业 6–7：BVH + 路径追踪器** |
| 17–22 | 材质（BSDF）、微表面、全局光照、动画模拟 | **作业 8：质点弹簧/模拟** |

> ⏱️ **给 4–6h/天的现实提醒**：GAMES101 全啃下来约 8–10 周。如果到第 6 周发现进度吃紧，**作业 8（模拟）可降级为"看懂即可"**，力保作业 1–7（软光栅化 + 路径追踪两大作品集核心）。

### 3.1 tinyrenderer 实战线（把理论写成 500 行 C++，产出作品集①）

> 项目：[github.com/ssloy/tinyrenderer](https://github.com/ssloy/tinyrenderer)，作者 Dmitry Sokolov。核心理念：**「我不打算教你怎么写 GPU 应用——我想让你搞懂它们底层怎么工作」**，这正是 TA 程序向要的渲染管线硬功夫。

**为什么加它（三大价值）**：

1. **理论↔代码闭环**：GAMES101 讲「理论 + 数学」，tinyrenderer 让你「动手写 500 行 C++ 软渲染器」，两者**同主题对照**（光栅化/深度/着色/纹理），学一讲写一课，理解翻倍。
2. **顺便补 C++**：纯 C++ 无第三方库，正好把你「只会语法」的短板在实战里磨掉（vector/类/指针/数学运算）。
3. **轻量产出即作品集**：10–20 小时跑通，比 GAMES101 作业更轻、更工程化，跑出来的 `framebuffer.tga` 截图直接就是**作品集①软光栅化器**（挂到博客 `/projects/`）。

**13 课与 GAMES101/202 的对照表**：

| tinyrenderer 课 | 内容 | 对应课程 | 阶段 |
|---|---|---|---|
| 1. Introduction | 软渲染器总览 + 装环境 | GAMES101 第 1 讲 | Phase 0 |
| 2. Bresenham 画线 | 直线光栅化 | GAMES101 第 5 讲 | Phase 1 |
| 3. 三角形光栅化 | 扫描线填充 | GAMES101 第 5 讲 | Phase 1 |
| 4. 重心坐标 | 顶点属性插值 | GAMES101 第 8–9 讲 | Phase 1 |
| 5. z-buffer | 深度缓冲/遮挡 | GAMES101 第 6 讲 | Phase 1 |
| 6–7. 相机 | 投影变换 | GAMES101 第 3–4 讲 | Phase 1 |
| 8. 着色 | Blinn-Phong 光照 | GAMES101 第 7 讲 | Phase 1 |
| 9. 纹理 | 纹理采样/uv | GAMES101 第 8–9 讲 | Phase 1 |
| 10. 法线贴图 | 切线空间 | GAMES101 第 10 讲+ | Phase 2 |
| 11. 阴影映射 | Shadow Map | GAMES202 阴影 | Phase 2 |
| 12. SSAO | 间接光照 | GAMES202 SSAO | Phase 3 |
| 13. Toon 卡通着色 | NPR | 呼应 NPR Demo | Phase 3 |

> **学法（同主题对照）**：GAMES101 第 5 讲（光栅化）看完 → 立刻写 tinyrenderer 第 2–3 课（画线 + 填三角形）。第 13 课 toon shading 直接就是 Phase 3「二次元 NPR 渲染」的原型，无缝衔接。

## 五、力扣 + C++ 双线程（从 <50 起步的补强路线）

### 5.1 力扣节奏调整

- **Phase 0–1（前 6 周）**：先做 **easy 打底**，每天 3 道（数组→哈希→字符串→链表），目标是建立"看到题就有思路"的手感，不追求难题。
- **Phase 2 起**：进入 medium 专题（栈/单调栈/二叉树/二分/滑窗/图/DP）。
- **完整 12 周专题清单**见 [`ta-leetcode-daily.md`](../ta-leetcode-daily.md)——它是路线图，不是硬性任务表；你从 <50 起步，**允许每周少做几道，但要"做一道、吃透一道、写一篇题解"**。

### 5.2 C++ 补强线（关键新增，每天 20min 融入块 3）

你的 C++ 是"会语法"，面试会挂在这里，必须专项补：

| 周 | C++ 专题 | 对应知识点 |
|---|---|---|
| 1–2 | STL 容器用法 | vector/map/unordered_map/set/stack/queue 的增删查与复杂度 |
| 3–4 | 内存管理 | 栈/堆、new/malloc、shared_ptr/unique_ptr/weak_ptr、循环引用 |
| 5–6 | 面向对象底层 | 虚函数表 vtable、多态、深浅拷贝、构造/析构顺序 |
| 7–8 | 现代 C++ | 移动语义、右值引用、完美转发、模板基础 |
| 9+ | 面试高频 | 内存对齐、vector 扩容/迭代器失效、map vs unordered_map |

> 每专题对应一篇博客（`src/content/posts/cpp-*` 已有内存/多态/关键字模板可复用）+ 一条 KB `note`。

## 六、UE5 副线（暂停 gameplay，转材质/渲染）

你已有 UE5 基础（49 集），**不浪费**，但方向从"角色/AI/战斗"转到"画面"：
