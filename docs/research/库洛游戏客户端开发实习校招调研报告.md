### 3.2 高频技术面试题清单（30+ 条）

> ⚠️ **重要说明**：以下题目按库洛面经帖覆盖的方向（C++、算法、图形学、UE 引擎，均有上述直接来源帖）及游戏客户端岗公开高频题库整理，**是备考题库而非逐字原文**。每条都是该方向面试中的常见问法，具体到库洛某一场面试的实际出题，请以真题汇总 PDF 与个人面经为准。

#### A. C++（9 条）

1. 虚函数/多态的实现原理是什么？（虚函数表 vtable、虚函数指针 vptr、内存布局、继承下的覆盖）
2. 构造函数和析构函数可以是虚函数吗？为什么？基类析构函数为什么要声明为 virtual？
3. 智能指针 shared_ptr / unique_ptr / weak_ptr 的区别与实现原理？（引用计数、循环引用、weak_ptr 如何解决循环引用）
4. new 与 malloc 的区别？delete 与 free 呢？（构造/析构调用、类型安全、重载）
5. C++ 内存对齐的规则与作用？给一个结构体算 sizeof。
6. vector 的扩容机制（倍增策略、迭代器失效）？map 与 unordered_map 的区别与适用场景？
7. 左值/右值/移动语义：std::move 的原理？完美转发？
8. 深浅拷贝的区别？拷贝构造函数/拷贝赋值运算符的写法与坑（浅拷贝导致的 double free）？
9. static / const / inline / extern "C" 关键字的作用？

#### B. 数据结构与算法（8 条，多为手撕）

10. 手撕：反转链表 / 判断链表是否有环并找环入口 / 合并两个有序链表。
11. 手撕：二叉树前/中/后/层序遍历（迭代版也要会）；求二叉树深度/最近公共祖先（LCA）。
12. 手撕：快速排序 / 归并排序，各自时间空间复杂度？快排最坏情况与如何避免？
13. 哈希冲突的解决方式（链地址法、开放寻址法）？为什么 unordered_map 用链地址法？
14. 手撕：TopK 问题（堆 / 快速选择）；堆的插入与调整（上浮/下沉）。
15. 手撕：二分查找及其变体（查找第一个/最后一个等于目标值的元素）。
16. 手撕：LRU 缓存（双向链表 + 哈希表）的实现与复杂度。
17. 滑动窗口 / 双指针类题目（笔试与手撕高频）。

#### C. 操作系统与计算机基础（6 条）

18. 进程与线程的区别？协程呢？线程间共享什么、独享什么？
19. 进程间通信方式（管道、共享内存、消息队列、信号量、socket）及各自适用场景？
20. 死锁产生的四个必要条件？如何预防/避免/检测？
21. 虚拟内存与分页机制？缺页中断？页面置换算法（LRU/FIFO/时钟）？
22. 内存池/对象池的原理？为什么游戏开发中大量使用对象池（避免内存碎片与频繁 malloc）？
23. 多线程同步：互斥锁 vs 自旋锁 vs 条件变量 vs 原子操作？什么场景用哪个？

#### D. 计算机图形学（9 条）

24. 现代渲染管线的完整流程？（顶点输入→顶点着色器→曲面细分→几何着色→光栅化→片元着色→测试与混合）
25. 前向渲染 vs 延迟渲染的区别、优缺点？各自适合什么场景？（《鸣潮》等开放世界常见延迟渲染/移动端混合方案）
26. 坐标变换：模型矩阵/视图矩阵/投影矩阵的作用？齐次坐标的意义？如何判断点在相机前方？
27. 光照模型：Phong / Blinn-Phong 区别？PBR 基本概念（BRDF、金属度、粗糙度、能量守恒）？
28. 阴影：Shadow Map 的原理？阴影失真（shadow acne）如何解决？软阴影思路？
29. 抗锯齿：MSAA / FXAA / TAA 的原理与区别？
30. 纹理采样：mipmap 的作用与各向异性过滤？纹理压缩（ASTC/ETC）？
31. 骨骼动画与蒙皮的原理？动画混合（blend）？
32. 渲染性能优化：视锥剔除、遮挡剔除、LOD、合批（DrawCall 优化）、Overdraw 控制？移动端 GPU（TBDR 架构）渲染注意点？

#### E. Unreal 引擎（9 条）

33. UObject、AActor、UActorComponent 的关系与生命周期？（引擎启动→GameInstance→World→Level→Actor→BeginPlay→Tick→EndPlay→GC）
34. UE 的垃圾回收机制：UObject 如何被 GC？引用/AddToRoot/UPROPERTY 标记的作用？C++ 对象 vs UObject 的内存管理区别？
35. Tick 机制：Actor 的 Tick 与引擎 Tick 组（TG_PrePhysics 等）？大量 Actor 时如何优化 Tick？
36. 蓝图与 C++ 如何交互？UE 反射机制（UCLASS/UPROPERTY/UFUNCTION 宏）的作用？
37. Gameplay 框架：GameMode / GameState / PlayerController / Pawn / PlayerState 的分工？
38. 网络同步：Replication / RPC 原理？帧同步 vs 状态同步？锁步（lockstep）？
39. 资源加载：硬引用 vs 软引用（TSoftObjectPtr）？异步加载（LoadObject / StreamableManager / AssetManager）？打包后的资源寻址（Package/路径）？
40. UE 的多线程模型：游戏线程 / 渲染线程 / RHI 线程？Stat 性能分析命令（stat unit / stat gpu 等）？
41. 物理与碰撞：碰撞检测流程（Broadphase 八叉树/SAP）、碰撞通道（Object Type / Collision Profile）？

#### F. 游戏开发常识与其他（6 条）

42. 游戏主循环（Game Loop）的组成？固定时间步长（Fixed Timestep）解决什么问题（帧率无关的运动）？
43. 帧率与逻辑帧的区别？网络游戏中"帧同步"与"状态同步"各有什么坑？
44. 缓存友好：为什么连续内存（数组 vs 链表）遍历更快？（CPU 缓存局部性，游戏开发高频考点）
45. 你做过的最有挑战的项目/Demo 是什么？架构怎么设计的？遇到过最难排查的 Bug 是怎么定位的？（项目深挖必问）
46. 了解《鸣潮》/《战双帕弥什》吗？如果是你，会怎么优化其中某个系统的性能？（考察对公司的了解）
47. 反问环节：你还有什么问题？（建议准备 2-3 个有深度的问题，如项目渲染管线、技术栈演进）

**备考建议**：优先把 A/B 两类（C++ 基础 + 手撕算法）练熟，这是面经帖里"凉经"最常见的挂点；C/D/E 三类按"能讲清原理 + 能举 UE/游戏中的例子"准备；F 类结合自己项目准备 2-3 个完整的故事。可对照华南理工官方整理的《库洛游戏校招&实习 面试经验真题汇总》PDF 自测。
