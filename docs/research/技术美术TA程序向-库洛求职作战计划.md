## 一、先厘清：TA 程序向到底要什么

技术美术（Technical Artist, TA）是**连接程序与美术的桥梁**，按侧重点分三类。你要走的是**程序向 / 渲染向**：

| 方向 | 核心职责 | 与客户端开发的区别 |
|---|---|---|
| **渲染 TA（你主攻）** | 材质系统、Shader 编写、光照/阴影、NPR 卡通渲染、后处理、性能优化 | 客户端写 gameplay 逻辑；TA 写"画面怎么算出来" |
| **管线 TA** | DCC（Maya/Blender/Houdini）工具链、Python 自动化、资产导入/规范 | 更偏"流程工具"，脚本量大 |
| **工具 TA** | 编辑器工具、批量处理、资源管理插件 | 偏 C++/Python 工具开发 |

**程序向 TA 的八块能力拼图**（按优先级排序）：

1. **图形学 + 渲染**（核心）：渲染管线、光照、阴影、PBR、NPR——**GAMES101/202 正是这一块的地基**
2. **Shader 语言**：HLSL（UE）、GLSL（OpenGL/ShaderToy）——能写出可跑的着色器
3. **C++**：扎实（工具/插件/运行时 Shader 底层都要用）
4. **线性代数/数学**：向量、矩阵、坐标变换、插值（面试 + Shader 日常）
5. **引擎**：UE 材质编辑器 + 蓝图 + HLSL + Niagara + Lumen/Nanite 原理
6. **DCC 工具**：Blender/Maya 基础、Houdini（程序化生成，加分项）
7. **Python**：管线自动化、批量处理脚本（MEL/Python）
8. **数据结构与算法**：笔试/面试必考，力扣刷题（每天 3 道）

> ⚠️ **关键认知**：客户端开发和 TA 的算法要求**高度重叠**（C++ 基础 + 手撕 + 图形学），你已有的 UE5/C++ 底子和力扣积累**不会浪费**，反而是 TA 面试的加分项。真正要**新增**的是：Shader 实战、材质系统、DCC 管线、数学直觉。

## 二、两门在学教程定位与主线

### GAMES101（现代计算机图形学入门 · 闫令琪）——"地基"

- **地位**：全球公认的图形学入门第一课，22 讲。**TA 面试的图形学原理题 90% 出自这门课。**
- **覆盖**：模型/视图/投影变换、光栅化、Blinn-Phong 着色、纹理映射、几何（曲线/曲面/网格）、光线追踪、材质（BSDF）、动画与模拟。
- **作业（必做，作品集来源）**：
  - 作业 1-2：**软光栅化器**（MVP 变换 + 三角形光栅化 + 深度测试）→ 简历"渲染管线理解"的硬证据
  - 作业 3：着色（Phong/法线贴图/凹凸贴图）
  - 作业 4-5：贝塞尔曲线 + 几何
  - 作业 6-7：**BVH + 路径追踪器** → 简历"全局光照/光线追踪"的硬证据
  - 作业 8：质点弹簧 / 模拟

### GAMES202（高质量实时渲染）——"实时渲染进阶"

- **地位**：GAMES101 的进阶，11 讲，是**游戏引擎实时渲染的核心**，直接对应《鸣潮》这类项目。
- **覆盖**：Shadow Mapping（PCF/PCSS/VSSM/SDF 软阴影）、全局光照（SSAO/SSR/光探针/LPV/VXGI/RTX）、PBR（microfacet/Disney/预计算）、抗锯齿（TAA/SMAA）。
- **作业（必做）**：Shadow Map、PRT（球谐函数）、SSR、PBR 材质。

**主线结论**：GAMES101 → GAMES202 是 TA 渲染向的**黄金标准路径**。学习策略是**「视频 + 作业 + 笔记」三线并行**——只看视频不做作业 = 白学；作业产出直接进作品集。

## 六、拓展教程清单（按需推进，不贪多）

### 图形学 / 渲染（主线延伸）
- **GAMES103**：物理模拟（刚体/软体/布料）——理解"模拟"这块
- **GAMES104**：现代游戏引擎架构——理解引擎全貌
- **GAMES105 / GAMES201**：角色动画 / 高级物理引擎（按需）
- **LearnOpenGL / LearnOpenGL-CN**：工程化 OpenGL + GLSL，把 GAMES101 理论落成代码
- **Ray Tracing in One Weekend**：手写光追，补 GAMES101 作业 6-7 的延伸
- **The Book of Shaders**：Shader 创作入门（免费，碎片化时间看）
- **《Real-Time Rendering》第 4 版**：TA 必读书（英文，做工具书查）

### Shader / 材质（核心实战）
- **ShaderToy**：每天抄一个经典效果，理解 GLSL 思维
- **Ben Cloward 的 Shader 教程**（B 站有译）：UE 材质节点的神级教程
- **《Unity Shader 入门精要》（冯乐乐）**：中文 Shader 书，入门友好
- **UE 官方 Material/后处理教程 + Niagara**

### 数学（补直觉）
- **3Blue1Brown**《线性代数的本质》《微积分的本质》——图形学数学的直觉来源
- **Khan Academy** 线性代数（需要硬核推导时）

### 工具 / DCC / Python（管线向）
- **Blender**：免费，学建模/UV/烘焙基础（理解美术侧）
- **Houdini**：SideFX 学习版免费，程序化生成（TA 加分项）
- **Substance Painter/Designer**：理解 PBR 贴图工作流
- **Python**：官方教程 + 一个真实管线脚本（批量重命名/导入导出）
