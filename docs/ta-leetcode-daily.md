# 力扣刷题清单：TA（技术美术·程序向）每天 3 道 · 12 周专题计划

> 配套主计划见 [`技术美术TA-专属定制学习计划.md`](./技术美术TA-专属定制学习计划.md)。
> 节奏：每周 6 天（周一~周六），每天 3 道；周日复盘 + 重刷错题。语言用 **C++**（面试笔试主力）。
> 做题方法：先自己想 15 分钟 → 看题解 → 合上重写 → 写题解进博客（`src/content/posts/leetcode-*`）。

## ⚠️ 起步说明（重要：你是 <50 题 + C++ 会语法的起点）

- **这是 12 周路线图，不是硬性任务表**。你当前力扣 <50 题、C++ 只会语法，请按下面节奏**降速打底**：
  - **前 2 周**：只做第 1–2 周的**数组/哈希 easy 题**，每道题顺手补一个 C++ 知识点（vector/map 的增删查、string 操作），建立"看到题→有思路→写得出来"的手感。
  - **第 3 周起**：再按清单顺序推进，遇到 medium 卡壳很正常，**允许每天只吃透 2 道 + 重刷 1 道错题**。
- **C++ 补强线**（每天 20min 融入刷题）见主计划 5.2 节：STL 容器 → 内存管理 → 多态/虚表 → 移动语义 → 面试高频。
- **原则**：做一道、吃透一道、写一篇题解；宁可慢，不可空转。
