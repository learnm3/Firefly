## 一、JD 拆解（唯一靶子）

**SUN-美术TA实习生｜广州｜技术类｜日常实习生招聘｜28 届**

要做的事：

1. 用 UE5 最新特性做**影视级写实**场景/角色/特效/动作物理/UI 的渲染和交互
2. 把美术创意抽象成**可落地的技术需求**，做艺术—技术桥梁，兼顾性能
3. 写**渲染管线技术文档**、研究新渲染技术/工具、组织内部分享

要的能力：

1. 28 届本科及以上
2. 懂完整美术流程：概念 → 建模 → 绑定 → 动画 → 特效 → 最终渲染
3. 熟悉 UE、Shader 编程和主流渲染技术，能写高效渲染代码
4. 熟悉 Maya/Houdini/Blender 之一，会脚本
5. 美术基础：造型、色彩、构图、光影
6. 热爱游戏、关注行业趋势
7. 会沟通、能团队合作
8. 有影视级写实经验优先

一句话：**懂美术流程 + 能用 UE5/Shader/DCC 脚本把画面做出来 + 能写文档分享**。作品集比课程进度重要。
