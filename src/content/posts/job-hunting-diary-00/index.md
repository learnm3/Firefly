## 一、本周最重要的决定：从 UE5 转向 Unity

这一周做了一次**关键方向调整**：放弃 UE5/C++ 主线，转向 **Unity/C# 方向**。

### 为什么转？

- **库洛有 Unity 项目**：《战双帕弥什》是 Unity 开发，Unity 客户端岗是真实需求
- **就业广度更大**：Unity 在国内游戏公司（米哈游/鹰角/叠纸等二次元厂商）使用极广
- **技术可迁移**：之前积累的图形学（渲染管线/光照）、算法（13 篇游戏情境题解）、引擎通用概念，在 Unity 下依然有效——不是白学

### 放弃了什么？

UE5 方向的 7 篇学习笔记（Character/GAS/网络同步等）已隐藏（draft），不是删除——它们记录了学习能力，未来如果需要随时可恢复。

### 得到了什么？

一份更符合实际求职的 **188 天 Unity 计划**（详见[求职宣言](/posts/career-plan-kuro-intership/)与[求职路线图](/roadmap/)）：Unity 入门 → MMO 全栈 → XLua 热更新 → 就业冲刺。

## 三、现状复盘

### 3.1 技术栈盘点

| 方向 | UE5 阶段 | Unity 阶段 |
|---|---|---|
| C# / Unity | 无 | 🔴 从零开始（最大短板） |
| C++ | 有笔记沉淀 | 🟢 语法/内存概念可辅助理解 C# |
| 图形学 | 渲染管线/光照笔记扎实 | 🟢 通用知识，Unity 渲染相通 |
| 算法 | 13 篇游戏情境题解 | 🟢 差异化亮点，持续保持 |

### 3.2 关键认知

1. **引擎是工具，不是信仰**：UE 和 Unity 的底层概念相通，选择要看目标公司需求，而不是哪个"看起来高级"
2. **时间紧迫，计划保守**：188 天是下限，寒假和春招就要投递，每一天都要算着用
3. **热更新是硬通货**：XLua 热更新是国内客户端岗高频考点，必须拿下
