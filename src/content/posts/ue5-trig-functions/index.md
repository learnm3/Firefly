## 本集要解决的问题

想在游戏里做**平滑的往复运动**（物体上下浮动、来回摆动），最优雅的数学工具就是三角函数。本集先把 `sin` / `cos` 的"是什么、为什么是波浪线、怎么和游戏时间挂钩"讲清楚。

---

## 一、把正弦函数想成"黑箱"

把 `sin` 想成一个**黑箱**：

- 输入一个值 `t`（`sin(t)`）；
- 输出一个值 `sin(t)`。

问题只剩一个：**它拿输入 `t` 做了什么？**

### 直角三角形定义

画一个直角三角形，选一个角记为 **θ**（希腊字母，数学传统上用 θ 表示角度）：

- **对边**：与 θ 相对的边；
- **邻边**：与 θ 相邻（非斜边）的边；
- **斜边**：直角对面的最长边。

定义：

- `sin(θ) = 对边 / 斜边`
- `cos(θ) = 邻边 / 斜边`

三角函数和直角三角形密不可分——但游戏里我们更常用下面这个视角。

---

## 二、单位圆：sin = y，cos = x

画一个**单位圆（半径为 1）**：

- 周长 = `2π × 半径 = 2π`（因为半径是 1）；
- 从 x 轴上的点 `(1, 0)` 出发，沿圆周走一段距离，从圆心连到所在点——这条线段**长度永远是 1**（半径）；
- 于是你总能和 x 轴构成一个直角三角形，斜边 = 1。

套用上面的定义：

- `sin(θ) = 对边 / 斜边 = 对边 / 1 = 对边` —— 而"对边"恰好就是该点的 **y 坐标**；
- `cos(θ) = 邻边 / 斜边 = 邻边 / 1 = 邻边` —— 恰好就是该点的 **x 坐标**。

> **结论（单位圆上的核心等式）：沿单位圆走，某点的坐标就是 `(cos θ, sin θ)`。** 换句话说 `x = cos θ`、`y = sin θ`。

---

## 三、弧度：另一种"角度单位"

沿单位圆走，走过的**弧长**本身就是角度的一种度量——这叫**弧度（radian）**：

| 角度 | 弧度 | 直观含义 |
| --- | --- | --- |
| 360° | `2π` | 绕单位圆一整圈（周长 = 2π） |
| 180° | `π` | 半圈 |
| 90° | `π/2` | 四分之一圈 |
| 45° | `π/4` | 八分之一圈 |

**为什么在意弧度？** 因为 `sin` / `cos` 在数学与引擎里**几乎总是按弧度**（而不是度）来定义和计算。后面写代码时看到 `π/2`、`π`、`2π` 要能立刻换算成 90°、180°、360°。

---

## 四、为什么正弦是"波浪线"：周期性

把单位圆上点的 y 值（= sin）随角度 `t` 画成图：

1. `t = 0`：点在 `(1,0)`，`sin 0 = 0`；
2. 走到 `t = π/2`：y 升到最大值 **1**；
3. 走到 `t = π`（180°）：y 回到 **0**；
4. 走到 `t = 3π/2`：y 降到最小值 **-1**；
5. 回到 `t = 2π`：y 回到 **0**，开始重复。

于是 `sin` 的图像是一条在 **+1 与 -1 之间平滑振荡**的曲线，每 `2π` 重复一次——这就是**周期性**。

`cos` 图像**形状完全一样**（`x = cos t` 从 1 开始：`t=0` 时 `cos=1`，`π/2` 时到 0，`π` 时到 -1……）：

> 两条曲线其实**是同一根曲线**，只是 `sin` 比 `cos` **平移了 `π/2`**（相位差）。

---

## 五、游戏开发里怎么用：把时间喂进 sin

代码里"角度"从哪来？——**让时间流逝来充当 `t`**：

```cpp
// 伪代码思路（下一集会在 UE 中落地）
float t = GetWorld()->GetTimeSeconds();   // 累计的游戏时间（每帧加 DeltaTime 的效果）
float Offset = FMath::Sin(t);             // 在 -1 ~ 1 之间周期变化
Actor->SetActorLocation(Z + Offset * 幅度); // Z 坐标上下浮动
```

- 每帧把 `DeltaTime` 累加成的"时间 `t`"喂给 `sin`；
- 得到的 `sin(t)` 在 -1 到 1 间周期变化 → 把它当**位移量**加到物体的 Z（或 X）上；
- 物体就会**平滑地上下/来回浮动**——这种运动叫**正弦波（sine wave）行为**。

> 这就是本集"美丽"的地方：一条数学曲线，直接变成游戏里常见的浮动、摇摆、呼吸灯等效果。后续课程（例如给 Item 加"悬浮高度"）会正式在 C++ 里实现它。

---

## 小结

- `sin(θ) = 对边/斜边`、`cos(θ) = 邻边/斜边`（直角三角形）；
- 单位圆上：`x = cos θ`、`y = sin θ`（半径 1）；
- 弧度制：`360° = 2π`、`180° = π`、`90° = π/2`，引擎三角函数默认用弧度；
- `sin`/`cos` 以 `2π` 为周期，值域 `[-1, 1]`；两者只差 `π/2` 相位；
- 游戏用法：`时间 t`（累计 DeltaTime / GetTimeSeconds）→ `sin(t)` → 当作位移给物体 → 正弦波运动。
