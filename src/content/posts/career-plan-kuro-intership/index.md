## 一、目标与背景

**目标岗位**：库洛游戏（Kuro Games）客户端开发实习生

**代表作**：《鸣潮》（UE5）、《战双帕弥什》（Unity）

**我的背景**：软件工程大二学生，会写代码但 C++ 底子薄；看过大量 UE5 教程，动手落地少；算法在刷但远不够。

**投递窗口**：2026 年秋招日常/寒假实习（9-11 月）

> ⚠️ **残酷的现实**：从现在到投递窗口只剩约 3 个月，我的 C++ 还撑不起一场技术面试。这不是慢慢学的节奏，是**冲刺**的节奏。

---

## 二、现状盘点（SWOT）

| 维度 | 现状 | 判断 |
|---|---|---|
| C++ | 学过课程，能写基础代码，STL/内存/多态不熟 | 🔴 **最大短板**，游戏客户端面试第一关 |
| 引擎 | 看过大量教程（Character/Montage/IK），笔记质量高但没落地 | 🟡 有认知没实践，缺一个能跑的项目 |
| 图形学 | OpenGL 系列笔记进行中 | 🟢 方向对，需补渲染管线深度 |
| 算法 | LeetCode 高频题进行中，已有题解沉淀 | 🟢 保持节奏即可 |
| 博客 | 内容质量高，已成体系 | 🟢 简历上的差异化亮点 |

**结论**：我的优势是**学习方法和输出能力**（博客证明），短板是**硬技能落地**。计划要做的就是把「看过」变成「做过」。

## 三、四阶段冲刺计划（2026.08 → 2026.11）

### 阶段一（08-15 ~ 08-31）：地基补强 —— C++ 从薄弱到能写工程代码

C++ 是客户端面试的第一道门槛。两周时间把语法 → 内存 → STL 形成闭环。

**每日节奏（4-6h）**：

| 时段 | 内容 | 时长 |
|---|---|---|
| 上午 | C++ 专题（类/多态/内存/STL） | 2h |
| 下午 | LeetCode 2 题 + 写题解 | 1.5h |
| 晚上 | UE5 环境搭建 / 复盘整理 | 1-1.5h |

**验收标准**：

- [ ] 能独立写出带智能指针、虚函数、移动语义的类
- [ ] 能讲清 vtable、内存布局、STL 容器复杂度
- [ ] LeetCode 完成 30 题（累计）
- [ ] 产出一篇《C++ 内存管理专题》博客

### 阶段二（09-01 ~ 09-14）：引擎落地 —— UE5 3C Demo 从 0 到可玩

把笔记变成项目。**客户端面试最看重能跑的东西**。

- 角色移动/相机/动画三件套完整落地（复用已有笔记）
- Montage 技能动画 + 武器 IK
- 渲染管线 + OpenGL 光照立方体
- 产出：Demo 项目页 + 渲染管线笔记

### 阶段三（09-15 ~ 09-30）：作品打磨 —— 战斗 Demo + 简历

把 3C 升级成带技能的完整小作品，这是简历的**核心弹药**。

- GAS 技能系统：连招/闪避/受击扣血
- 战斗反馈：伤害数字、受击闪白、屏幕震动
- 项目文档 + README + 演示录屏
- 简历 STAR 化 + 作品集整理

### 阶段四（10-01 ~ 11-30）：冲刺投递 —— 笔试面试全流程

进入实战节奏，**投递不是终点，复盘才是**。

- 每周投递 10+ 岗位（库洛官网/牛客/内推）
- 每周 1-2 套模拟笔试（严格计时）
- 每场面试 24h 内复盘，写进[求职日记](/posts/job-hunting-diary-00/)
- 保持每日刷题手感

> 详细任务清单和勾选进度在 [求职路线图](/roadmap/) 页面，[面试题库](/interview/) 页面同步维护复习清单。

## 四、求职策略思考

### 4.1 为什么选客户端而不是服务端/测试？

客户端是游戏技术的**入口**：渲染、引擎、性能、手感，离玩家最近，反馈最直观。我的图形学与 UE 兴趣都指向这里。

### 4.2 库洛之外，广撒网

游戏行业秋招讲究**多投多面**。库洛、米哈游、腾讯、网易、鹰角、叠纸等一并投递，面试经验是通用的，每一场都是练兵。

### 4.3 博客在求职中的角色

这份求职规划本身就是博客内容——**用公开输出的方式倒逼自己执行**。面试官看到的不只是简历上的一行字，而是：

- 持续 3 个月的学习记录（学习能力证明）
- 高质量的 UE5/图形学笔记（技术深度证明）
- 项目复盘与踩坑记录（工程思维证明）
