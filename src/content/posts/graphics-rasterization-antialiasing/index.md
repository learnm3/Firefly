## 二、第 5 课：把三角形变成像素

### 2.1 视口变换：从规范立方体到屏幕

上一课结束时，所有 3D 物体都被投影、挤压进了规范立方体 `[-1,1]³`。屏幕可不管什么立方体，它只认**像素阵列**：

- 像素索引 `(x, y)`，x、y 是整数，范围 `(0,0)` 到 `(width−1, height−1)`
- 像素 `(x, y)` 的**中心**在 `(x + 0.5, y + 0.5)` —— 因为像素是一个覆盖 `[x, x+1] × [y, y+1]` 的小方块
- 屏幕覆盖范围是 `(0,0)` 到 `(width, height)`

视口变换就是把规范立方体的 xy 平面从 `[-1,1]²` 拉伸平移到 `[0,width] × [0,height]`：

```
Mviewport = [width/2  0     0    width/2 ]
            [ 0     height/2 0    height/2]
            [ 0       0     1      0     ]
            [ 0       0     0      1     ]
```

> **面试必答**：视口变换与 z 无关。z 被原样保留，后面深度测试（Z-Buffer）才用它。像素中心是 `(x+0.5, y+0.5)` 不是 `(x,y)`，用错会导致画面整体偏移半格。

另外，有时透视投影不给 l/r/b/t，只给两个参数，用相似三角形换算：

```
tan(fovY/2) = t/|n|      aspect = r/t
```

- `fovY`：垂直视场角（眼睛张开的"上下角度"）
- `aspect`：宽高比（画面"横着比竖着宽多少"）

### 2.2 光栅显示设备（了解即可）

"Raster"在德语里就是"屏幕"，**Rasterize = 画到屏幕上**。不同时代的显示设备成像方式不同：

- **CRT 阴极射线管**：电子枪发射 → 聚焦 → 加速偏转 → 电子束扫荧光屏发光；老电视用隔行扫描（先扫奇数行再扫偶数行）
- **帧缓冲 Frame Buffer**：图像本质是一张 2D 颜色数组，数字 RGB 经 DAC（数模转换）变成模拟信号驱动显示器
- **LCD 液晶**：扭转偏振"透光/挡光"，背光照明
- **LED 阵列 / 电子墨水（Kindle）**：前者发光二极管点阵，后者带电粒子上下移动显色

本课程统一简化：**像素 = 发出均匀颜色方块光的显示单元**。

### 2.3 为什么偏偏是三角形？

几乎所有 3D 模型都由三角形网格构成。三角形如此"万能"，因为：

- 最基础的多边形，任何多边形都能拆成三角形
- 三个点必共面，天然是平面
- 内部有明确判定法（叉积同侧测试）
- 顶点属性（颜色、法线、UV）可以在三角形内部**重心插值**——后续着色全靠这个

### 2.4 光栅化 = 对指示函数做 2D 采样

光栅化的输入是三角形三个顶点投影到屏幕后的位置，输出是一组近似它的像素。核心思路非常简洁：

定义一个指示函数 `inside(tri, x, y)`：点在三角形内返回 1，否则返回 0。然后**遍历每个像素，用像素中心去采样这个函数**：

```
image[x][y] = inside(tri, x + 0.5, y + 0.5)
```

采样值为 1 就点亮这个像素。判断 inside 用的是第 2 课的叉积：

```
对三条边依次做叉积，三个结果同号（全正或全负）→ 点在三角形内
```

```
        ▲
       / \
      /   \     ● 采样点在三角形内 → 点亮像素
     /  ●  \
    /       \       ○ 采样点在三角形外 → 不点亮
   ───────────
```

三个必须知道的细节：

1. **边界情况**：采样点恰好落在两个三角形共享的边上，需要约定归属（如 OpenGL 约定归某方向的三角形），否则相邻三角形会同时判定，出现裂缝或重叠
2. **加速 1 · Bounding Box**：先求出三角形的外接轴对齐包围盒，只遍历盒内像素，别扫全屏
3. **加速 2 · 增量三角形遍历**：沿扫描行逐个像素递推判断，适合细长且旋转的三角形

### 2.5 问题来了：锯齿

把采样结果发给显示器，三角形边缘会出现明显的**阶梯状锯齿（Jaggies）**：

```
  理想三角形            光栅化结果
  ┌───────┐           ┌───────┐
  │ █████ │   ────▶   │ █████ │
  │███████│           │█████░░│  ← 边缘一格格地"啃"
  └───────┘           └─────░░┘
```

原因一句话：**像素是均匀颜色的小方块，而三角形是连续函数**。用离散像素中心采样连续信号，边缘只能非 0 即 1，丢失了"部分覆盖"的中间信息。这是"采样"这个动作本身带来的错误，能不能做得更好？——第 6 课回答这个问题。

## 三、第 6 课：抗锯齿——先搞清楚错在哪

### 3.1 采样伪影：混叠（Aliasing）的三种形态

采样在图形学里无处不在：光栅化是采样二维位置、拍照是采样传感器平面、视频是采样时间。采样不足就会产生伪影：

| 伪影 | 中文 | 采样类型 | 表现 |
|---|---|---|---|
| Jaggies | 锯齿 | 空间采样 | 三角形边缘阶梯状 |
| Moiré | 摩尔纹 | 图像欠采样 | 隔行隔列抽帧后高频细节与低频花纹重叠 |
| Wagon Wheel | 车轮效应 | 时间采样 | 高速旋转的车轮看起来在倒转 |

> **根本原因**：信号变化太快（高频成分多），而采样太慢——采样率跟不上信号频率。三种伪影本质是同一种病，只是在不同轴上发作。

### 3.2 频域视角：为什么欠采样会"伪装"

要理解混叠，需要把信号从"空间域"切到"频域"。**傅里叶变换**把任意函数表示成一系列正弦、余弦的加权和：

```
f(x) = A/2 + (2A/π)cos(t·θ) − (2A/3π)cos(3t·θ) + (2A/5π)cos(5t·θ) − …
```

关键直觉（不需要会算傅里叶变换，只需要懂这张图）：

```
低频信号：采样点够密 → 重建得很好
～ ～ ～ ～ ～ ～ ～ ～
    ●  ●  ●  ●  ●        → 基本还原

高频信号：采样点不够密 → 重建出"假的低频"
∿∿∿∿∿∿∿∿∿∿∿∿∿∿∿
    ●  ●  ●  ●  ●        → 看起来像低频（别名！）
```

**在给定采样率下无法区分的两个频率，互称"别名"（Aliases）**。高频信号被欠采样后，样本"骗"你它是个低频信号——这就是 Aliasing 名字的由来。

### 3.3 滤波与卷积：怎么去掉高频

滤波 = 去掉某些频率成分：

- **高通滤波**：只留高频 → 留下图像边缘
- **低通滤波**：去掉高频 → 图像变模糊

卷积 = 滑动窗口内的局部加权平均：

```
信号: 1  3  5  ...       滤波器: [1/4, 1/2, 1/4]
      ┌─────────────┐
      │1×(1/4)+3×(1/2)+5×(1/4) = 3 │  ← 窗口滑动，处处求平均
      └─────────────┘
```

> **卷积定理**：空间域卷积 = 频域相乘。想滤波可以空间域滑窗，也可以变到频域相乘再变换回来，结果等价。

**Box Filter（盒式滤波器）**——3×3 全 1/9 的均值滤波就是低通滤波，把每个像素变成周围 9 个像素的平均。**滤波器核越宽，保留的频率越低（越模糊）**。

### 3.4 采样 = 重复频谱（混叠的机理图）

频域里有一个关键结论：**采样等价于把原始频谱周期性重复**。

```
采样前：      ▓▓▓▓            （频谱）
采样后（密）： ▓▓▓▓  ▓▓▓▓  ▓▓▓▓  ▓▓▓▓  ← 副本间隔远，不重叠
采样后（疏）： ▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓  ← 副本重叠 → 混叠！
```

- 提高采样率 = 拉大副本间隔（副本不再重叠）
- 先滤波 = 把频谱变窄（副本即使靠近也不重叠）

这两条就是抗锯齿的全部思路来源。

## ★ 重点：为什么必须先滤波后采样？

这是第 6 课最核心的问题，也是面试高频题。

**错误做法**（先采样再滤波）：

```
采样 → 高频已经被"伪装"成低频混进信号 → 滤波只是把混叠"模糊掉"
结果：模糊了的混叠（blurred aliasing），锯齿还在，只是变糊了
```

**正确做法**（先滤波再采样）：

```
滤波 → 先去掉高于奈奎斯特（Nyquist）频率的高频 → 采样时频谱副本不再重叠
结果：真正没有混叠的平滑边缘
```

> 一句话：**滤波去掉的是"会混叠的高频"，而不是"混叠的结果"**。顺序错了，问题已经发生，后面做什么都是亡羊补牢。

## 四、实践：MSAA 到底在干什么

理论说"先对像素面积做平均再采样"，实现上有个漂亮的近似——**MSAA（超采样抗锯齿）**：

```
普通采样：每像素 1 个样本（像素中心）
  ●            ●
      ●            ●
  结果：要么红要么白，边缘锯齿

2×2 MSAA：每像素 4 个子样本
  ● ●         ● ●         ● ●
  ● ●   →    ● ●   →    ● ●
  4 个样本各自判断 inside    统计：3/4 在三角形内 → 像素显示 75% 颜色
```

**MSAA 的实现步骤**：

1. 每个像素内部取 `N×N` 个采样点（如 2×2 = 4 个、4×4 = 16 个）
2. 每个子样本各自做 inside 判断
3. 统计落在三角形内的子样本占比（如 3/4），作为像素的颜色强度

```
2×2 MSAA 边缘像素示例：
  ████ ██░░      ← 75% 覆盖 → 显示 3/4 强度的颜色
  ██░░ ░░░░      ← 25% 覆盖 → 显示 1/4 强度的颜色
  边缘出现"中间色"过渡，视觉上就平滑了
```

> **面试必答**：MSAA 的代价是采样与内存开销约为 N² 倍（2×2 是 4 倍）——"没有免费的午餐"。MSAA 不是提高分辨率，是提高每像素的采样数。

### 现代抗锯齿（了解即可）

- **FXAA**（Fast Approximate AA）：后处理近似抗锯齿，速度极快但边缘可能发虚
- **TAA**（Temporal AA）：利用时间上多帧的信息抗锯齿
- **DLSS**（超分辨率/超采样）：从低分辨率重建高分辨率，本质上仍是"样本不够"的问题，用深度学习补样本

## 五、一句话串起两课

```
MVP 投影 → 规范立方体 → 视口变换（立方体→屏幕，与 z 无关）
→ 光栅化 = 像素中心采样 inside(tri,x,y)（叉积判定 + Bounding Box 加速）
→ 采样不足 → 混叠（锯齿/摩尔纹/车轮效应）
→ 抗锯齿 = 先低通滤波去高频，再采样
→ 实现 ≈ MSAA（每像素 N×N 子样本按覆盖比例平均）
→ 下一课：多个三角形遮挡怎么办（Z-Buffer）
```
