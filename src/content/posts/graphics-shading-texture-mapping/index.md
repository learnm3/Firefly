# GAMES101 第7-8课：着色与纹理映射

> 本文是 [GAMES101 系列笔记](../../../posts/graphics-transformations-view-projection/) 的第 4 篇。上一篇：[第5-6课：光栅化与抗锯齿](../../../posts/graphics-rasterization-antialiasing/)。

## 0. 知识链：这一篇解决什么问题

前两篇回答了两个问题：**三角形怎么画出来**（光栅化）、**画出来怎么不锯齿**（抗锯齿）。
这一篇补上两个新问题：

1. **谁遮挡谁？** —— 两个三角形都覆盖同一个像素时，显示哪一个？（Z-Buffer）
2. **每个像素该是什么颜色？** —— 给表面"涂色"（着色），并在不同位置贴上不同图案（纹理映射）。

```
┌────────────┐  ┌────────────┐  ┌──────────────┐  ┌──────────────┐  ┌─────────────┐
│ L5 光栅化   │→│ L6 抗锯齿   │→│ L7 可见性     │→│ L7 着色       │→│ L8 纹理映射   │
│ 三角形→像素 │  │ 采样与滤波 │  │ Z-Buffer     │  │ Blinn-Phong  │  │ (u,v) 坐标   │
└────────────┘  └────────────┘  └──────────────┘  └──────────────┘  └─────────────┘
```

## 1. Z-Buffer：遮挡问题的"正确答案"

### 1.1 画家算法为什么不行

**画家算法**：先画远处的三角形，再画近处的，后画的覆盖先画的——像画家先涂背景再画近景。

问题有二：

- 需要按深度**排序**，复杂度 O(n log n)；
- 存在**深度交叠**（互相穿插的三角形）时，排序也无解。

### 1.2 Z-Buffer 的做法

对**每个采样点（像素）**维护一个"当前最近的东西"的深度值：

- 帧缓冲（frame buffer）存颜色；
- 深度缓冲（z-buffer）存深度；
- 约定：**z 恒为正，z 越小越近**；初始深度置为 ∞。

光栅化三角形时逐采样点判断：

```
if (z < zbuffer[x, y]) {
    framebuffer[x, y] = rgb;   // 更近，覆盖
    zbuffer[x, y] = z;
} else {
    /* 被遮挡，什么都不做 */
}
```

### 1.3 三个必须记住的性质

| 性质 | 原因 |
|---|---|
| 复杂度 **O(n)** | 不是排序，而是逐采样点比较，恒定覆盖假设下与三角形数量线性 |
| **与绘制顺序无关** | 谁近谁显示，先画谁都行 |
| 全部 GPU **硬件实现** | 最重要的可见性算法 |

## 2. 着色（Shading）：定义与"局部性"

**着色**：在字典里是"给插画加阴影或涂色"；图形学里，是对物体表面某点应用材质、计算其颜色。

**着色是局部的（Shading is Local）**：只计算着色点处反射向相机的光。输入：

- 观察方向 **v**（view）
- 表面法线 **n**（normal）
- 光照方向 **l**（light，每个光源一个）
- 表面参数（颜色、反光强度等）

> ⚠️ **着色不产生阴影（shading ≠ shadow）**！阴影是全局问题——光线被别的物体挡住。局部着色模型根本不知道这些。这是高频易错点。

## 3. Blinn-Phong 反射模型：三项加起来

```
L = La + Ld + Ls
```

### 3.1 漫反射（Diffuse）——Lambert 余弦定律

光被表面**均匀散射**，因此颜色**与观察方向无关**；但接受到多少光能取决于光线与法线的夹角：

```
Ld = kd (I/r²) max(0, n·l)
```

- `kd`：漫反射系数（颜色）
- `I/r²`：光的距离衰减
- `max(0, n·l)`：背面不接受光（余弦取非负）

### 3.2 高光（Specular）——Blinn-Phong 的核心技巧

高光集中在镜面反射方向附近，**依赖观察方向**。直接算反射方向 R 太费劲，Blinn-Phong 用**半程向量**：

```
h = (v + l) / ||v + l||        // v 与 l 的角平分线
Ls = ks (I/r²) max(0, n·h)^p
```

直觉：**v 接近镜面反射方向 ⇔ h 接近法线 n**。用 `n·h` 度量"接近"。

`p` 是反光指数：p 越大，`cos^p` 曲线越窄，高光斑越小越集中（表面越光滑）。

### 3.3 环境光（Ambient）

一个"假"的常量项，补偿被忽略的间接光照、避免阴影全黑：

```
La = ka·Ia
```

### 3.4 完整模型

```
L = ka·Ia + kd(I/r²)max(0, n·l) + ks(I/r²)max(0, n·h)^p
```

**面试必答**：为什么漫反射与视角无关、高光与视角有关？——漫反射向所有方向均匀散射；高光只在镜面反射方向附近显著，观察方向是否靠近它决定亮度。

## 4. 着色频率：Flat / Gouraud / Phong

同一个模型可以在不同频率上着色：

| 频率 | 在哪一级 | 插值什么 | 效果 |
|---|---|---|---|
| **Flat**（逐面） | 每个三角形一个法线 | 无 | 块状感，不适合光滑表面 |
| **Gouraud**（逐顶点） | 顶点法线 | 先算顶点颜色，再插值**颜色** | 过渡平滑，但高光易失真 |
| **Phong**（逐像素） | 每个像素 | 插值**法线**，再逐像素算完整着色 | 高光最精细 |

```
Flat:   ▣▣▣▣   （每块一个颜色）
Gouraud:▣▨▩▣   （颜色渐变）
Phong:  ●▣▨▩   （法线渐变 → 平滑高光）
```

> ⚠️ **Phong shading（逐像素着色频率）≠ Blinn-Phong reflectance model（反射模型公式）**。一个说"在哪着色"，一个说"怎么算光照"。

### 法线从哪来？

- **顶点法线**：最好直接来自底层几何（如球面解析已知）；否则**平均相邻面法线**；
- **像素法线**：重心插值（第 9 课正式讲），插值后**必须重新归一化**再用。

## 5. 图形管线：实时渲染的五级流水线

```
顶点流 → 屏幕空间顶点 → 三角形流 → 屏幕空间三角形 → 片元流 → 着色片元 → 像素
```

| 阶段 | 做什么 |
|---|---|
| ① 顶点处理 | Model / View / Projection 变换，3D 顶点放到屏幕空间 |
| ② 三角形处理 | 顶点组装成三角形 |
| ③ 光栅化 | 采样三角形覆盖的像素（第 5 课） |
| ④ 片元处理 | 对每个片元着色：Blinn-Phong + 纹理映射 |
| ⑤ 帧缓冲操作 | Z-Buffer 可见性测试等，写入像素 |

**Shader 程序**：可编程阶段，逐顶点/逐片元执行。GLSL 片段着色器示例：

```glsl
uniform sampler2D myTexture;
uniform vec3 lightDir;
varying vec2 uv;
varying vec3 norm;

void main() {
    vec3 kd = texture2D(myTexture, uv).rgb;
    kd *= clamp(dot(-lightDir, norm), 0.0, 1.0);
    gl_FragColor = vec4(kd, 1.0);
}
```

- `uniform`：整帧不变的参数；`varying`：由光栅化器插值的逐片元值（uv、norm）；
- **GPU**：图形管线的专用并行处理器，现代 GPU 约 2–4 Tera-FLOPs 着色器算力。

## 6. 纹理映射：让表面"长"出图案

### 6.1 为什么需要

球面有图案、地板有木纹——**不同位置不同颜色**。单一漫反射系数 kd 只能一色到底，不够。

### 6.2 核心思想：表面是 2D 的

每个 3D 表面点，都有它在 2D 纹理图像上的对应位置 **(u, v)**：

```
屏幕空间 ──光栅化──▶ 世界空间 ──查表──▶ 纹理空间 (u,v)
```

- 每个三角形**顶点**被分配纹理坐标 (u, v)；
- 三角形在屏幕上光栅化时，每个像素的 (u,v) 由顶点插值得到；
- 从纹理图"复制"对应的一小块贴到表面。

```
3D 表面三角形                    2D 纹理
      A ●                        (0,1) ●
       /\                              /\
      /  \                            /  \
   B ●----● C                    (0,0)●----● (1,0)
```

### 6.3 复用与平铺

一张纹理可多次使用：同一块小纹理重复铺满表面（地板砖、墙面）。

### 6.4 下一课预告：重心插值

三角形内部任意点的 (u,v) 怎么算？——**重心坐标（Barycentric coordinates）**，第 9 课正式讲。它不仅能插值 (u,v)，还能插值法线、颜色等一切顶点属性。

## 9. 高频易错点

- 着色是局部的，**不产生阴影**（shading ≠ shadow）；
- **Phong shading ≠ Blinn-Phong reflectance model**，名字像但不是一回事；
- 半程向量 h 是 v 与 l 的**角平分线**，不是镜面反射方向 R；
- Z-Buffer 与绘制顺序无关、O(n)，因为是逐采样点比较而非排序；
- 插值得到的法线**必须先归一化**再用于光照计算。
