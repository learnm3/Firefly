> **唯一靶子**：库洛「SUN-美术 TA 实习生」JD（2026-11 截图）。
> **方向**：用**程序向 TA** 的能力去打这个美术 TA 岗——UE5 渲染 + Shader/HLSL + 性能 + 工具 + 图形学是主武器；美术只做"判断/沟通"训练，不练长期绘画。
> **判断标准**：每学一个东西，必须回答——对应 JD 哪一条？产出什么证据？面试能讲 3 分钟吗？三个都答不上，就不学/延后。

| 12 | **行业/竞品** | 要求 6 | 每周 1 次鸣潮/战双/3A 拆解或行业文章 | 每周 1 条拆解 |

### 学到什么程度就停（防止无限深挖）
- **材质**：会做 8–10 个材质、能参数化、能讲原理 → 停；不追求写论文级。
- **Shader**：3–5 个效果 + 后处理 1 个 → 停；不手写整套 BRDF。
- **性能**：能做基线、找瓶颈、量化优化 → 停；不读引擎源码。
- **Blender**：建模/UV/导出/脚本 → 停；不学角色雕刻/绑定。
- **美术**：能判断、能沟通 → 停；不追求画技。

## 4. 学习顺序（按"动作"排，不按"课程"排）

### 阶段 0：零基础 10 天（现在，每天 40–60 分钟）
见 `10_零基础10天重启.md`：UE 界面/放物体/材质/灯光/相机/曝光/小场景/Blender 道具/导入。产出 **2 张图**。
> GAMES101 不排；美术判断每天 10–15 分钟拉片。

### 阶段 1：第 11–30 天（程序向技术主线）
- 按 `09_技术向_30天启动.md` 的 D1–D21：灯光/曝光 → 材质 → 后期/MRQ → Custom Node → 工具/PipeCheck。
- GAMES101 每周 2 讲：L03 → L05 → L06 → L07 → L08（先这 5 讲）。
- 产出：P2 灯光成图、Material Lab v0.1、PipeCheck v0.1、性能基线。
- 美术判断：每天 1 张拉片。

### 阶段 2：第 31–60 天（P2 完整作品 + Shader 包）
- P2 白模→材质→灯光→MRQ→15s 镜头→Breakdown + 性能卡。
- P3 材质/Shader 包：PBR 5 个 + 风格化 3 个 + HLSL 2–3 个 + 后处理 1 个。
- GAMES101：L09 → L13 → L15–16 → L19–20。
- 产出：作品集 v0.5（2–3 件）+ 作品集页面。

### 阶段 3：第 61–90 天（P4 角色/VFX + P5 工具 + Showreel）
- P4：MetaHuman/授权角色材质 + 三点布光 + Niagara 1 个 + 25s 视频。
- P5：PipeCheck v1（UI/配置/测试）+ README + 演示视频。
- 产出：4 件作品 + 60–90s Showreel + 性能报告；按 `07` rubric ≥80 分再投。

### 阶段 4：投递/面试（2027 春日常实习练手；2027-08 下旬秋招）
- 投递：SUN 美术 TA（主）+ 程序向 TA（双投）+ 同类。
- 面试：每件作品讲 3 遍；15 题技术自测；模拟面试。

## 5. 每周时间怎么分

| 线 | 占比 | 内容 |
| --- | --- | --- |
| 技术主线 | **70%** | UE5 渲染 / Shader / 工具 / 性能（跟着 09 的 D 卡） |
| 美术判断 | **15%** | 每天 10–15 分钟拉片；不画长期作业 |
| 输出/行业 | **15%** | Breakdown、笔记、每周 1 条拆解 |

**标准周 16h**：工作日每晚 90–120 分钟（含 10 分钟拉片）+ 周六 4h 项目 + 周日 1.5h 复盘。
**保底周 8h**：每天 25–50 分钟；只保技术主线 + 10 分钟拉片。

## 6. 判断"该不该学"的 4 个问题

1. 它对应 JD 的哪一条？（职责 1/2/3，要求 2/3/4/5/6/7/8）
2. 学完产出什么**可展示**的东西？（图/GIF/代码/报告/文档）
3. 面试官问它，我能不能讲 3 分钟？
4. 如果现在不学，会不会挡住下一个作品？

> 四个答案都是"否"→ 不做。三个"否"→ 延后。
> 收藏教程、看长课、装更多软件，都不算学习。
