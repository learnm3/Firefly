## 1. 岗位原文（2026-11 截图）

**职位描述**
1. 使用 UE5 最新引擎特性开发**影视级写实**场景 / 角色 / 特效 / 动作物理 / UI 等渲染和交互效果；
2. 与美术团队紧密合作，将美术创意抽象为**可落地的技术需求**，充当"艺术-技术桥梁"，确保艺术设想在不同硬件平台的性能约束下仍能完整实现；
3. 编写维护**渲染管线技术文档**，研究引入新渲染技术和工具，定期组织内部分享。

**职位要求**
1. 本科及以上学历，**28 届**毕业生；
2. 了解完整美术流程：概念原画 → 建模 → 绑定 → 动画 → 特效 → 最终渲染，能在任意环节发现并提出技术改进建议；
3. 熟悉 UE 引擎、**Shader 编程**及主流渲染技术，能写高效渲染代码；
4. 熟悉 Maya / Houdini / Blender 等一种以上软件，具备**脚本开发能力**；
5. 扎实美术基础：**造型、色彩、构图、光影**感知灯光，能判断资源质量；
6. 热爱游戏，关注海内外热门游戏、行业最新技术动态；
7. 乐于交流，具备良好的团队合作和沟通能力；
8. **有影视级写实效果开发经验者优先**。

## 7. 面试官怎么筛你（三条硬门槛）

1. **画面门槛（30 秒）**：打开作品集第一眼，画面有没有"影视级"的质感、光影是否可信、构图是否舒服。→ 对应美术基础和写实渲染。
2. **技术门槛（5 分钟）**：随便指一个效果，能不能讲清楚"为什么这么做、还有什么做法、代价是什么、性能怎么样"。→ 对应 Shader、渲染原理、性能意识。
3. **协作门槛（10 分钟）**：给你一个美术需求（比如"我想要这个角色的头发在逆光下有通透感"），你能不能翻译成技术方案并说清限制。→ 对应美术流程认知、文档、沟通。

> 所以作品集不是"图片墙"，而是**"画面 + 技术说明 + Breakdown"三件套**。

## 9. 你的"不公平优势"和"最大风险"

**优势（要放大）**
- 编程 + 工程能力：大部分美术出身的 TA 编程弱，你能写工具、能读引擎代码，这是差异化。
- 输出习惯：会写博客/复盘 → 直接满足 JD 的"文档 + 分享"。
- 完整项目经验：做过课程项目、部署过东西 → 沟通和排期能力可信。

**风险（要防）**
- 美术审美是慢变量，**不能靠突击**，只能每天 10–15 分钟拉片/看图（速写可选）。
- 计划上瘾：容易花一整天整理计划而不动手 → 本系统规定：**计划时间每周 ≤ 1 小时**。
- 教程囤积：收藏了 = 学会了 → 本系统规定：**一次只跟一门课，看完必须产出**。
- 完美主义：一个材质调 3 天 → 规定：**每个小任务 2 小时上限，超时先记录再跳过**。
