> 作品集不是"图片墙"，是 **画面 + 技术 + Breakdown** 三件套。
> **方向：程序向 TA 的作品集**——每件作品必须有技术证据（Shader/节点截图、工具代码、性能数据、可复现参数）；画面是载体，不是全部。
> 推荐排序：**P3 材质/Shader 包、P5 工具** → P2 写实场景（承载）→ P4 角色/特效（技术角度）。
> 4 件核心作品分别对应 JD 的 4 组能力；练习作品不进作品集（但可以发学习记录）。

**原则**
- 4 件核心作品 = 场景（P1/P2）+ 材质 Shader（P3）+ 角色特效（P4）+ 工具（P5），正好覆盖 JD 的四面。
- 每件作品必须配 **Breakdown**（目标、参考、技术方案、参数、踩坑、性能、复盘），这是 TA 岗和纯美术岗的分水岭。
- **少而精**：宁可 4 件都能讲 5 分钟，不要 10 件都讲不清。

## 1. 练习件（不进作品集，但要认真做）

### 练习 A · 霓虹灯牌（Blender，已有）
- 目的：熟悉 Blender 建模/发光材质/渲染，建立"我能出图"的信心。
- 产出：1 张渲染图 + 5 张过程截图。
- 处理：发 B站动态可以，作品集不收录。

### 练习 B · 弗洛洛 UE5 渲染（已有工程）
- 目的：完整走一遍贴图→材质→摄影棚灯光→渲染，理解 PBR 与角色材质。
- **版权**：鸣潮角色模型仅供个人学习，**不要公开发布到作品集/ArtStation/B站**；可以写"学习笔记"但用截图打码/局部。
- 产出：3 张渲染图 + 1 篇私用笔记（记录参数与踩坑）。
- 之后：用 MetaHuman 或自制/授权角色替代，做成 P4。

## 2. P1 · 室内写实小景 "First Light"

**目标画面**：一个可信的室内空间，光影有故事感（清晨/黄昏/雨夜），完成度到"能当作品集第一页"。
**选题（三选一，范围小）**：废弃车库 / 林间小屋 / 雨夜便利店。

**范围**
- ✅ 做：1 个空间 + 3–5 个道具 + 1 套灯光故事 + 后期 + 3–5 张图 + 10 秒镜头。
- ❌ 不做：角色、动画、复杂特效、超大开放世界。

**步骤（约 4 周）**
| 周 | 任务 |
| --- | --- |
| 1 | 参考板（PureRef 10 张）+ 白模 blockout + 机位/构图 |
| 2 | 材质：地面/墙面/金属/布料/玻璃（母材质 + 实例） |
| 3 | 灯光：主光/补光/环境光/体积雾 + 后期调色（3 版对比） |
| 4 | MRQ 出图 + 10s 镜头 + Breakdown |

**交付物**
- [ ] 3–5 张 1920×1080 渲染图（含 1 张特写）。
- [ ] 10 秒 Sequencer 镜头（1080p，MRQ）。
- [ ] 1 篇 Breakdown（参考→白模→材质→灯光→后期→成图，每步 1 图 + 3 行说明）。
- [ ] 参数/性能记录（Lumen 开关、曝光、显存、帧率）。

**验收（M1）**
- 能对着图讲 5 分钟：为什么这样打光、材质怎么分层、哪里做了取舍。
- 画面没有明显穿帮（漏光、接缝、材质重复感）。
- 有人（同学/网友）能看出"这是 UE 做的写实场景"。

**降级方案**：时间不够 → 只做 3 张静帧，砍视频；再不够 → 2 张图 + 1 篇 Breakdown，但必须有。

## 3. P2 · 霓虹街角 "Neon Rain"（作品集主作品）

**目标画面**：雨夜霓虹街道，湿地面反射、霓虹色溢、体积雾、电影感镜头。
**已有基础**：`portfolio/SUN_TA_01`（L_NeonStreet + M_NeonCyan + Lumen/VSM/Nanite 配置）——直接在这个工程上迭代，别重开。

**范围**
- ✅ 做：街角 1 个 + 招牌/霓虹灯 + 湿地面 + 雨/雾 + 3 个镜头 + 自定义材质（湿地面/霓虹闪烁）+ 后期。
- ❌ 不做：完整城市、角色、载具动画、复杂蓝图玩法。

**技术亮点（面试要讲）**
1. **湿地面**：Roughness 变化 + 法线 + 反射（Lumen 反射 + 屏幕空间细节），不是单纯贴一张图。
2. **霓虹自发光**：Emissive + Bloom 阈值 + 颜色分级，控制"过曝但不脏"。
3. **雨/雾**：Niagara 雨丝 + 体积雾 + 灯光散射，讲清性能代价。
4. **镜头**：Sequencer 3 机位 + 景深 + 轻微手持抖动。
5. **性能**：1080p 下目标 ≥30fps（MRQ 离线不计），记录显存/DrawCall/三角面。

**步骤（约 6 周）**
| 周 | 任务 |
| --- | --- |
| 1 | 参考板 + storyboard + blockout + 机位 |
| 2 | 建筑/招牌建模（Blender）+ 资产导入 |
| 3 | 材质：湿地面/霓虹/墙面脏迹/涂鸦 |
| 4 | 灯光 + 雾 + 后期（第一版 3 图） |
| 5 | 精修 + Niagara 雨 + 镜头动画 |
| 6 | MRQ 出片 + 性能记录 + Breakdown 定稿 |

**交付物**
- [ ] 3–5 张成图（含 1 张霓虹特写）。
- [ ] 15 秒镜头视频（1080p，MRQ，含简单字幕说明技术点）。
- [ ] Breakdown（含节点截图、参数、性能数据）。
- [ ] 1 篇技术文章（发博客/B站专栏）。

**验收（M2）**
- 画面第一眼有"电影感"，不是"UE 默认场景感"。
- 能讲清 3 个技术点 + 每个的代价和替代方案。
- 性能数据真实可复现。

## 4. P3 · 材质 / Shader 包 "Material Lab"

**目标**：证明你会写材质、能参数化、能讲原理——这是美术 TA 最核心的技术证据。

**内容清单（8+3）**
| 类型 | 内容 | 要求 |
| --- | --- | --- |
| PBR 材质 ×5 | 金属（划痕）、布料（绒感）、皮肤（SSS）、玻璃（折射）、湿地面 | 每个是母材质 + 实例，参数暴露 |
| 风格化 ×3 | Ramp 卡通光照、Outline 描边、Rim 边缘光 | 能切换/叠加 |
| HLSL Custom ×2–3 | 溶解 Dissolve（带边缘发光）、三平面映射、UV 流动/扫描线 | 手写 HLSL，不是纯节点 |
| 后处理 ×1 | 描边 / 暗角 / 自定义调色 | 叠加在场景上演示 |

**交付物**
- [ ] 一个展示场景：材质球阵列 + 应用示例（同一物体切换材质）。
- [ ] 每个材质 1 张 GIF（参数变化演示）+ 节点截图 + 3 行参数说明 + 性能备注。
- [ ] 一页文档（Markdown/PDF）：材质列表、参数表、使用说明、复现步骤。
- [ ] 可选：打包成 `.uasset` 素材包（版权自己的）。

**验收**
- 别人拿到文档能复现 80%。
- 能讲清"为什么用 Custom Node 不用节点"、"这个效果的性能代价"。

## 5. P4 · 角色渲染 + Niagara 特效

**目标**：展示角色材质/布光/特效/镜头综合能力，对应 JD"场景/角色/特效"。
**模型来源（三选一）**
1. **MetaHuman**（免费，最稳，适合写实）。
2. 自制低模角色（Blender，难度高，但原创）。
3. 授权/CC0 模型（标注来源）。
> ⚠️ 不要用鸣潮角色公开发布。

**范围**
- ✅ 做：1 个角色 + 皮肤/眼睛/头发材质 + 三点布光（含轮廓光/逆光）+ 1 个 Niagara 特效 + 25 秒镜头。
- ❌ 不做：角色绑定/动画（可用 MetaHuman 自带或简单待机动画）、复杂布料模拟。

**技术亮点**
1. 皮肤 SSS + 眼睛高光/折射 + 头发各向异性（讲清参数）。
2. 角色布光：主光/补光/轮廓光/背景光，色温对比。
3. Niagara：技能特效（能量/火焰/粒子拖尾），讲 spawn/update 逻辑。
4. Sequencer 镜头 + 景深 + 后期。

**交付物**
- [ ] 3 张角色成图（正面/侧面/特写）。
- [ ] 25 秒视频（角色 + 特效 + 镜头）。
- [ ] Breakdown（材质/灯光/特效/参数）。

**降级**：时间不够 → 只做角色静帧 3 图 + 特效 GIF，砍视频。

## 6. P5 · DCC 管线工具 "PipeCheck"（技术差异化）

**目标**：证明你"能写工具、懂管线、能写文档"，直接对应 JD 职责 3 和"艺术-技术桥梁"。

**功能（Blender 插件，Python）**
1. **命名检查**：按项目规范检查物体/材质/贴图命名，列出违规项。
2. **资产体检**：三角面数、贴图尺寸、UV 是否重叠/拉伸、材质槽数量、LOD 缺失。
3. **一键导出**：按预设导出 FBX（轴向/缩放/命名），输出到指定目录。
4. **报告输出**：生成 HTML/CSV 报告（红黄绿分级），可发给美术。
5. **UI 面板**：Blender 侧边栏面板，按钮 + 参数。

**加分（可选）**
- UE 侧 Python 脚本：批量导入/资产校验/自动重命名。
- 预设配置：不同项目（写实/卡通）不同规范。

**交付物**
- [ ] GitHub 仓库：README（安装/使用/截图）、代码、LICENSE、示例资产。
- [ ] 2 分钟演示视频（问题 → 工具 → 报告）。
- [ ] 一篇技术文档：为什么做、怎么设计、怎么测试、局限。

**验收**
- 能在你自己的 P2/P4 项目上真实跑一遍。
- 同学能按 README 装上并跑通。
- 面试时能讲"这个工具解决了什么真实痛点"。

## 7. 作品集页面结构（ArtStation / B站 / 个人网站）

### 每件作品页（顺序固定）
```
1. Hero 图（最强一张，占满屏）
2. 一句话说明：做了什么 + 技术点（例："雨夜霓虹街角，Lumen + 自定义湿地面材质 + Niagara 雨"）
3. 目标与参考板（3–5 张）
4. 白模 / blockout（证明流程）
5. 材质 / 灯光 / 后期（关键步骤图 + 参数）
6. 成图（3–5 张，多机位）
7. 技术拆解（3–5 个点，每点 2–3 行 + 截图）
8. 性能数据（帧率/显存/DrawCall/三角面）
9. 踩坑与复盘（2–3 条）
10. 工具/链接（GitHub/视频）
```

### Showreel（60–90 秒）
```
0–5s    最强镜头（抓人）
5–30s   场景/角色成片
30–50s  技术演示（材质切换/前后对比/节点）
50–70s  工具/其他作品
70–90s  名字 + 岗位 + 联系方式 + 作品集链接
```
- 配字幕说明技术点（面试官不一定开声音）。
- 1080p，H.264，文件 ≤200MB，同时传 B站 + 网盘。

### 简历（一页）
- 顶部：姓名/学校/专业/届别/联系方式/作品集链接/二维码。
- 技能：UE5（Lumen/Nanite/材质/Sequencer/MRQ）、Blender/Python、HLSL、图形学基础。
- 项目 3 条 STAR（每件作品 2 行：做了什么 + 技术 + 结果）。
- 其他：博客/GitHub/课程/奖项（不占太多篇幅）。

### 输出渠道
| 渠道 | 内容 | 频率 |
| --- | --- | --- |
| ArtStation | 作品集主页（英文标题） | 每件作品完成后 |
| B站 | 视频 + 专栏技术文章 | 每月 1 次 |
| 知乎 | 技术拆解文章 | 每月 1 篇（可选） |
| GitHub | P5 工具 + GAMES101 作业 | 持续 |
| 个人博客（Firefly） | Breakdown/复盘 | 每月 1 篇 |

### 版权与合规
- 游戏角色/解包资产：**只练习，不公开发布**。
- 第三方资产：标注来源与许可；商用素材包不要二次分发。
- MetaHuman：遵守 Epic 许可。
- 音乐/音效：用免版权或自己录。

## 8. 作品集自评表（调研版 rubric，≥80 分再投）

> 每项 1/3/5 分（C/B/A），加权后满分 5 分，×20 = 百分制。**≥80 分再投库洛，<60 分先补。**

| 维度 | 权重 | A（5 分，可直接面试） | B（3 分，需补） | C（1 分，不合格） |
| --- | --- | --- | --- | --- |
| 1. 写实还原与美术基础（造型/色彩/光影/构图） | 20% | 成片与参考差异小；构图有视觉引导；材质符合物理直觉 | 大体像，但光比/色温/粗糙度有硬伤 | 一眼假，参考与成品无关 |
| 2. UE5 渲染技术深度 | 20% | 能解释 Lumen/VSM/Nanite 参数取舍；能对比屏幕空间与硬件光追；说得清 MRQ/ACES 流程 | 会开 Lumen/Nanite，说不清为什么这样设 | 只会拖资产、开预设 |
| 3. 材质 / Shader 能力 | 15% | 有自写材质函数/HLSL；能解释 PBR 通道、混合模式、指令开销 | 会连基础节点、会改现成材质 | 只用现成材质 |
| 4. 性能与优化意识 | 15% | 给出帧时间/三角形数/材质指令数/显存；做过 LOD、Nanite 取舍、Overdraw 优化并量化收益 | 知道要看性能，但没有数据 | 完全没考虑性能（TA 岗一票否决） |
| 5. 管线 / 脚本 / 工具能力 | 10% | 有可运行的 Blender Python/UE 脚本/Houdini 工具，解决真实重复劳动 | 脚本很小（批量重命名等） | 无 |
| 6. 完整度与 Breakdown 表达 | 10% | 白模→材质→灯光→成片→性能数据齐全；文档可复现 | 有过程图，缺性能数据或文档 | 只有成片图 |
| 7. 影视级审美与镜头叙事（含 Showreel） | 10% | 有景别/焦段/景深/调色设计；Showreel 有节奏 | 静态好看但无镜头语言 | 无 Showreel |

**自评提示**：你的第 5 项（工具/脚本）可以最先拿 A；第 1 项（美术基础）是最大短板。**第一个项目就按「写实小场景 + 3 套灯光 + 完整性能数据 + Blender 工具脚本」做**，先把 2/4/5/6 拉到 A，再用 P4 补 1/3/7。

> **程序向 TA 调整**：技术证据（2/3/4/5 项）优先；美术项不要求 A，但不能出现"一眼假"。P3/P5 是底线作品，P2/P4 是画面载体。

## 9. 投递材料清单（v0.5：2027-03 前；v1.0：2027-07 前备齐）

## 10. 面试会问什么（美术 TA 向）

**作品追问**
- 这个场景的光为什么这么打？主光/补光/轮廓光分别在哪？
- 这个材质怎么分层的？为什么不用另一种做法？
- 性能怎么样？如果要在移动端跑，你怎么降级？
- 这个效果重不重？代价是什么？有没有替代方案？

**引擎/渲染**
- Lumen 和传统光追/烘焙的区别？Nanite 的限制？
- 虚拟阴影贴图（VSM）原理？后处理顺序？
- 材质节点怎么优化？什么时候用 Custom Node？
- TAA/TSR 的作用和副作用？

**Shader**
- 手写一个 Rim Light / 溶解边缘光 / 三平面映射，讲思路。
- 半透明材质的排序问题怎么处理？

**美术流程**
- 一个资产从原画到引擎的完整流程？你在哪一步介入？
- 美术说"我想要这个效果但性能不够"，你怎么沟通？

**工具**
- 你的工具解决什么问题？怎么测试？怎么让美术愿意用？

**行为面**
- 为什么库洛？为什么 TA？最近在学什么？遇到最大的困难？

**准备方式**：每件作品讲 3 遍并录音；每周 1 次模拟面试；把追问清单写下来逐条准备。

## 11. 风险与降级方案

| 风险 | 应对 |
| --- | --- |
| 时间不够 | 砍 P1 视频、P4 范围；保 P2 + P3 + P5 |
| 美术基础拖后腿 | 用资产 + 灯光/材质/后期 + Breakdown 取胜；强化"技术解释" |
| 8GB 显存 | 1080p、2K 贴图、路径追踪只出静帧、动画用 Lumen |
| 版权问题 | 游戏模型只练习；公开作品用 MetaHuman/自制/授权 |
| 同质化 | 用"自研 Shader + 工具 + 文档"差异化（大多数美术 TA 候选人没有工具作品） |
| SUN 信息不确定 | 官方未官宣；面试可请教但别断言，规划以 JD 能力项为准 |
| 投递无反馈 | 记录反馈、改作品集第一页、降低目标公司层级先拿面试 |
