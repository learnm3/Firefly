> 这一篇不是鸡汤，是**协议**：状态好时怎么不浪费，状态差时怎么不断线，没动力时怎么重启。
> 核心原则：**状态差不是你的错，是生理 + 环境 + 任务设计的问题。系统让你在低状态也能前进，而不是靠意志力硬扛。**

---

## 1. 每天 30 秒状态自检（09:00 和 19:30 各一次）

只看三个数，不用想太久：

| 问题 | 取值 |
| --- | --- |
| 昨晚睡了几小时？ | <6 / 6–7 / ≥7 |
| 身体感觉？ | 累 / 一般 / 有劲 |
| 情绪？ | 烦/丧 / 平静 / 兴奋 |

**判定规则**
- 睡 ≥7h + 有劲 + 平静/兴奋 → **S 高能**
- 睡 ≥6.5h + 一般 → **A 正常**
- 睡 <6.5h 或 累 或 烦 → **B 低能**
- 睡 <5.5h 或 生病/崩溃/哭过 → **C 恢复**

> 把结果点进 `学习面板.html` 的"今日状态"，它会给你当天的任务菜单。

## 2. 四档状态协议（照做，不要临场发挥）

### 🟢 S 高能（一周大约 1–2 天）
**原则：把最难的事放在今天，做 2 个 90 分钟深度块，不要用来刷教程。**

| 项目 | 内容 |
| --- | --- |
| 适合任务 | 写 Shader / 搭场景主体 / 调灯光 / 解决卡了很久的 bug / 作品集核心部分 |
| 时间块 | 90min + 休息 15min + 90min；下午不安排新的硬任务 |
| 环境 | 手机放另一个房间；关聊天；只开需要的那一个软件 |
| 结束标准 | 有一个"可截图/可 commit"的进展 |
| 禁止 | 不要用高能日整理文件、看教程、做计划——那是低能日的事 |

### 🟡 A 正常（大多数日子）
**原则：稳定推进，跟做 + 复现 + 小步交付。**

| 项目 | 内容 |
| --- | --- |
| 适合任务 | 跟教程做案例 / 材质调整 / 导入资产 / 修改已有作品 / Blender 建模练习 |
| 时间块 | 3 × 50min，中间休息 10min |
| 结束标准 | 当天任务清单完成 2/3 |
| 禁止 | 不要开新的"大项目"；不要同时学两个软件 |

### 🔴 B 低能（累、烦、学不进去）
**原则：不硬撑新知识，只做"低门槛 + 有产出"的事，保持连续性。**

| 项目 | 内容 |
| --- | --- |
| 适合任务 | 看 1 个 20 分钟教程片段 / 整理 5 张参考图 / 给现有材质改一个参数并渲染对比 / 写 3 行笔记 / 拉片或看图分析 1 张（速写可选） |
| 时间块 | 25min + 可选 25min |
| 结束标准 | 打开工程/笔记，做一个动作，打卡 |
| 禁止 | 不要开始学新概念；不要做需要连续思考 1 小时的事；不要自责 |

### ⚫ C 恢复（生病、崩溃、连续熬夜）
**原则：今天不学习，只恢复。恢复也是系统的一部分。**

| 动作 | 说明 |
| --- | --- |
| 睡眠 | 今晚提前 1–2 小时睡，比任何学习都重要 |
| 吃饭 + 水 | 好好吃一顿，别靠外卖糊弄 |
| 洗澡/散步 15 分钟 | 身体优先，情绪会跟着身体走 |
| 不评判 | 允许今天"零产出"；写一行"今天休息，明天 15 分钟重启"即可 |
| 禁止 | 不要刷学习类短视频制造焦虑；不要做重大决定（退课/换方向/放弃） |

> **C 状态连续 3 天以上** → 按 `03` §10 的断档恢复处理，并检查是不是计划排太满。

## 3. 状态切换策略

- **早上先判断，再安排**：S 日直接上硬任务；A 日先 20 分钟热身（整理桌面/看参考）再开始；B 日只排 1 个最小任务；C 日不排学习任务。
- **卡壳超过 30 分钟**：立刻执行三步——① 用 3 行写下问题（在做什么/现象/试过什么）；② 换一个任务（美术/整理/看参考）；③ 明天再看，或带着 3 行去问 AI/同学。**不要死磕到情绪崩。**
- **下午状态掉档**：把"需要创造"的任务换成"需要执行"的任务（导入、整理、渲染）。
- **晚上状态差**：只做 3 行复盘 + 准备明天的第一件事（把工程打开到该在的位置），然后睡。
- **周末**：至少留半天完全不碰学习；休息不是奖励，是系统要求。

## 4. 心流：怎么让自己"进入状态"

### 4.1 心流的 4 个条件（缺一个都进不去）
1. **目标清晰**：今天只做一件具体的事，写在便利贴上（"把地面材质做出湿感"而不是"学材质"）。
2. **即时反馈**：每调一个参数就渲染/看视口；每写一段就运行。
3. **难度匹配**：任务难度 ≈ 当前能力的 105%——太难会焦虑，太简单会无聊。
4. **无干扰**：手机不在视线内、关聊天、只开一个软件、戴耳机放白噪音/纯音乐。

### 4.2 90 秒启动仪式（每次开始前做）
```
1. 手机放到另一个房间 / 开飞行模式
2. 倒一杯水，桌上只留当前任务需要的东西
3. 在便利贴上写：今天这一块只做 ____（一个动作）
4. 打开工程/教程，把视角/页面调到"下一步"的位置
5. 设 25 分钟倒计时，点开始，先做 2 分钟"最笨的启动动作"
   （比如：随便挪一下摄像机、涂一笔、复制一个节点）
```
> 关键：**不要等"有状态"再开始，先做 2 分钟，状态会在做的过程中来。**

### 4.3 时间块选择
| 块长 | 适合 |
| --- | --- |
| 25 min | 低能日、启动困难、碎片时间 |
| 50 min | 常规跟做、材质调整 |
| 90 min | 高能日、Shader/灯光/场景主体、写代码 |

### 4.4 设计"即时反馈"（心流发动机）
- 每改一个参数 → 立刻看视口/渲染一张小图。
- 每完成一步 → 截一张图存进 `05_Renders`（进度可视化）。
- 每完成一个小功能 → git commit 一次，提交信息写"今天做了什么"。
- 用"前后对比"代替"完成度"：改之前截一张，改之后截一张。

### 4.5 心流杀手（看到就躲）
- 教程连环看（一个接一个，从不复现）
- 消息通知、手机在桌上
- 同时开 3 个软件/10 个标签页
- 目标模糊（"今天学 UE"）
- 完美主义（一个材质调 3 小时）
- 素材下载成瘾（收集 500 个资产，一个没用）

### 4.6 被打断后怎么回来
1. 写下被打断时正在做的"下一个动作"。
2. 回来后先做那个动作的 2 分钟版本。
3. 如果被打断超过 30 分钟，换 25 分钟短块重新启动。

### 4.7 心流日志（每周复盘时填）
| 日期 | 在做什么 | 进入心流了吗 | 当时的条件（时间/任务/环境） |
| --- | --- | --- | --- |
| 例：11-08 | 调霓虹材质 | 是 | 晚上 20:00、手机拿走、只开 UE、25min 块 |

> 3 周后你会发现自己的"心流配方"（什么时间、什么任务、什么音乐最容易进），然后复制它。

## 5. 热情引擎：怎么在 12 个月里不熄火

### 5.1 先想清楚"为什么"（写下来，贴在桌前）
- **愿景**：2027 年秋招，你能打开一个作品集网站，里面是你自己做的写实场景、角色、Shader 和工具，面试官说"这个画面不错"。
- **反愿景**（今晚就写 3 行）：2028 年毕业时，你打开电脑，里面只有课程作业、收藏夹里 200 个没看的教程、和一个"当时要是坚持就好了"的念头。
- **身份**：我不是"在学 UE 的学生"，我是**"能把美术创意变成 UE5 画面、还能写清楚怎么做的人"**。

### 5.2 用"作品"而不是"进度"驱动
- 不要记"今天学了 3 小时"，记"今天做出了一个能截图的东西"。
- 每两周必须发一次：B站动态 / 博客 / 朋友圈 / TalkArtist / ArtStation（哪怕只有一张图）。
- 作品是**唯一能对抗"我好像什么都没学会"的证据**。

### 5.3 建立正向反馈环
```
学一点 → 做个小效果 → 截图/录屏 → 发出去 → 有人点赞/评论 → 有动力继续
   ↑                                                        │
   └────────────────────────────────────────────────────────┘
```
- 初期不用等"完美作品"，发"今天调的材质对比图"也有人看。
- 把评论/点赞截图存起来，低状态时翻一翻。

### 5.4 榜样与参考（每周 1 次，30 分钟）
- 关注 3–5 个你想去的公司的 TA/美术（ArtStation、B站、知乎、TalkArtist）。
- 每周看 1 个高质量 Showreel/Breakdown，不是"看爽"，是**拆**：他用了几盏灯？材质怎么分层？镜头怎么动？
- 把最喜欢的 3 张图设成壁纸/贴在桌前——但**只和昨天的自己比**，不和天才比。

### 5.5 让"玩游戏"变成合法学习
- 每周 1 次 30 分钟"拉片式游戏"：玩的时候暂停，观察光影、材质、特效、UI。
- 写 3 行拆解发出去（"为什么这个场景看起来贵"）。
- 这样打游戏不再是"浪费学习时间"的罪恶感来源，而是行业输入。

### 5.6 社交与陪伴
- 找 1–2 个同样在学 TA/UE 的同学，每周互看一次作品、提 1 个意见。
- 加入 TalkArtist / B站 TA 社群，但**只潜水看作品，不刷焦虑**。
- 告诉家人/室友你的目标，让他们知道"晚上 8 点别叫我"。

### 5.7 奖励机制（里程碑才给）
- 完成 M1 → 买一个想要的小东西/吃顿好的。
- 完成 M3 → 换一个外设（鼠标/键盘/显示器，按预算）。
- 每次"连续打卡 21 天" → 给自己一天完全自由日。
- **不要用"学完就奖励游戏 5 小时"**——容易打乱睡眠，反而毁状态。

### 5.8 防止"热情烧穿"
- 每周 6 天学习 + 1 天完全休息（不是"学习但不学 UE"）。
- 每 4 周一个减载周（总量减半）。
- 睡眠优先：连续熬夜会让你第三天完全学不进去，得不偿失。
- 运动：每周 2–3 次 30 分钟（跑步/力量/散步都行），这是最便宜的情绪稳定器。

## 6. 情绪急救（按症状查）

### 6.1 焦虑（"来不及了/我太差了"）
1. 写下来：具体在担心什么（一句话）。
2. 分成"能控制 / 不能控制"两列；只对能控制的列 1 个动作。
3. 做 5 分钟最小任务（打开工程看 1 眼也算）。
4. 如果心跳快/胸闷：4-7-8 呼吸（吸 4 秒、憋 7 秒、呼 8 秒）×4 轮。

### 6.2 自责（"今天又没学"）
1. 承认：今天状态不好是事实，不是人格缺陷。
2. 写"最低限度版"：明天只做 15 分钟，具体做什么写清楚。
3. 不自罚、不"明天补 8 小时"——报复性学习必崩。
4. 看一遍你的反愿景和已完成清单（面板里有）。

### 6.3 比较焦虑（"别人 20 岁已经是 TA 了"）
1. 关掉小红书/抖音的"大佬日常"（算法会一直喂你）。
2. 记住：你看到的是别人剪过的第 100 版作品，不是他的第 1 版。
3. 写 3 条"我比 3 个月前强的地方"（哪怕很小）。
4. 把注意力拉回"本周交付"。

### 6.4 拖延（"打开 UE 就想刷手机"）
1. 把任务缩到 2 分钟："只打开工程，不要求做任何事"。
2. 环境隔离：手机放另一个房间，电脑只开 UE。
3. 用 25 分钟倒计时，只做一件小事。
4. 如果还是不想做，换任务（拉片/看图），别硬刚。

### 6.5 倦怠（"我不想学了，没意义"）
1. 先睡一觉/休息半天，倦怠首先是生理信号。
2. 回看 M1/M2 的作品，问自己："当时做出来的时候开心吗？"
3. 换一种输入：去玩你喜欢的游戏，做一次拉片；或者看一部电影。
4. 如果持续 2 周以上，认真评估：是计划太满、目标不适合，还是只是累了。**可以调整路线，但不要在崩溃的晚上做决定。**

## 7. 21 天启动习惯（前 3 周只做这一件事）

- **每天同一时间**（建议 19:30）做 **25 分钟**，内容不限（UE/Blender/美术/看教程都行）。
- 打卡条件：**打开工程/笔记 + 做 1 个动作**，不是"学满 25 分钟"。
- 绑定现有习惯：晚饭后 → 收拾桌子 → 打开面板 → 25 分钟。
- 断一天不重置，断两天从 15 分钟重启。
- 21 天后你会发现：打开工程这个动作不再需要"下决心"。

## 8. 每周复盘时记录的状态数据

| 指标 | 怎么记 |
| --- | --- |
| 平均能量 | 每天 1–5 分，周平均 |
| 心流次数 | 本周几次"进入状态忘了时间" |
| 断档天数 | 0 / 1–2 / 3+ |
| 睡眠达标 | ≥7h 的天数 |
| 运动 | 次数 |
| 最低动作完成 | 有几天做了"哪怕 15 分钟" |

> 这些数据比"学习时长"更能预测你能不能坚持 12 个月。连续两周能量 ≤2.5 → 下周减载。

## 9. 一页速查卡（打印/贴墙）

**状态差时，从下面选 1 个，做 10 分钟就够：**
1. 打开 UE 工程，转一圈视角，关掉。
2. 改一个材质参数，渲一张小图。
3. 拉片/看图 5 分钟（速写可选）。
4. 看 1 个 10 分钟教程片段，记 3 行。
5. 整理 5 张参考图到 `04_Refs`。
6. 给作品写 3 行说明。
7. 看 1 个 Showreel，记下 3 个你喜欢的点。
8. 拉片 1 帧：光从哪来、材质什么质感。
9. 清理桌面/工程目录（10 分钟）。
10. 写"明天最重要的一件事"，然后去睡。

**永远记住：**
- 状态差时**不硬撑新知识**，但也**不完全断**。
- 连续 2 天断档 → 15 分钟重启。
- 你不需要每天都很强，你只需要**每周都还在**。
