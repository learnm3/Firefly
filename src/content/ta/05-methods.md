> 一句话：**TA 不是"学"出来的，是"做"出来 + "讲"出来的。**
> 本文给你一套可复用的学习闭环、拆解方法、美术基础训练法和术语速查。学不进去、学了就忘、看了教程不会做的时候回来翻。

---

## 1. 总原则：70-20-10

| 比例 | 内容 | 说明 |
| --- | --- | --- |
| **70% 动手** | 在 UE/Blender 里做出东西 | 看 10 分钟教程，至少做 30 分钟 |
| **20% 输入** | 教程、文档、拉片、行业文章 | 只输入当前项目需要的内容 |
| **10% 复盘** | 笔记、Breakdown、讲解、发帖 | 不复盘 = 没学；讲不出来 = 没懂 |

> 常见错误是反过来：90% 看教程，10% 动手，然后产生"我学了很多"的幻觉。

---

## 2. 学习闭环（每个知识点都走一遍）

```
① 看 5–10 分钟（只看到能动手为止）
        ↓
② 跟做（一模一样复刻，不追求理解）
        ↓
③ 关掉教程，凭记忆重做一遍（这一步最痛苦也最有用）
        ↓
④ 做一个变体（换参数/换对象/换场景，验证是否真懂）
        ↓
⑤ 用 3 行话讲清楚：它是什么、为什么这样做、什么时候会出问题
        ↓
⑥ 存进笔记/博客（截图 + 参数 + 踩坑）
```

**判断是否学会的标准**：关掉教程，能在 15 分钟内从零做出 80% 的效果，并说出 2 个参数的作用。

## 3. 项目倒逼法（本系统的核心）

- 每个阶段只问一个问题："这个阶段结束，我要交付什么可展示的东西？"
- 带着问题去学：**先有画面目标（参考图），再倒推需要学什么**，而不是"先把 UE 学完再想做什么"。
- 项目范围要小：**一个空间 + 3–5 个道具 + 1 个光源故事**，就够一件作品。
- 允许"丑的第一版"：先跑通，再迭代；第一版的目标是"存在"，不是"好看"。

> 反面教材：花 3 个月看教程，作品集里 0 件作品。正面教材：3 个月做出一件粗糙但完整的小场景 + 一篇 Breakdown。

## 4. 拆解复刻法（看参考图 → 变成自己的能力）

### 4.1 拉片（每天/每周 10–30 分钟）
看到一张好图（游戏截图/影视帧/ArtStation），按顺序问：

1. **光**：主光从哪来？色温？硬度？有没有补光/轮廓光？阴影软硬？
2. **材质**：表面是金属/非金属？粗糙还是光滑？有没有污渍/磨损/水迹？
3. **色彩**：主色调？对比色？饱和度集中在哪？暗部偏冷还是偏暖？
4. **构图**：视觉中心在哪？引导线？前景/中景/背景怎么分层？
5. **技术**：这是实时还是离线？用了什么后期（Bloom/景深/暗角/色调）？

**输出**：在 PureRef 里拼一张参考板 + 写 3 行分析。一周 5 张，一年 250 张——审美就是这么练出来的。

### 4.2 技术复刻（做项目时）
1. 找 1 张"跳一跳够得着"的参考（比当前水平高 20%，不是大神作品）。
2. 拆成 3–5 个技术点（灯光方案/材质层次/构图/后期）。
3. 先做白模 blockout，确认比例和构图。
4. 一项一项复刻，每完成一项就对比参考图。
5. 全部完成后，并排对比，写"差在哪、为什么、下次怎么改"。

### 4.3 复刻 ≠ 抄袭
- 复刻是练习，**公开发布要写清楚参考来源**；作品集尽量做原创/授权素材。
- 用游戏角色模型（如弗洛洛）练习可以，但**不要公开发布到作品集**（版权风险）。

## 5. 美术判断训练（程序向 TA：每天 10–15 分钟，不练长期绘画）

> 你不需要成为插画师。TA 的美术基础目标是：**能判断好坏、能看出问题、能说出为什么**，而不是画得多好。
> **程序向调整**：把"画"降为可选，把"看 / 判断 / 拆解"作为主线；每天 10–15 分钟拉片即可，速写和临摹不占主线时间。

### 5.1 四个训练模块（每天选 1 个，轮换）
| 模块 | 怎么练 | 频率 |
| --- | --- | --- |
| **速写（可选）** | 临摹照片/参考，5–10 分钟一张，抓大形和比例 | 每周 1 次，不占主线 |
| **色彩** | 看一张图，判断主色/辅色/点缀色；做 3 色小色稿；临摹电影帧的色调 | 每周 1–2 次 |
| **构图** | 分析截图/电影帧的视觉中心、引导线、三分法、前景层次 | 每周 1 次 |
| **光影** | 看一张图，标出主光方向、色温、软硬、阴影；判断光源数量 | 每周 1–2 次 |

### 5.2 训练原则
- **看 > 画**：零基础阶段，"看懂"比"画好"重要 10 倍。
- **大量快速**：5–10 分钟一张，一周 5 张，不要一张画 3 小时。
- **只练"判断"**：每张图问 3 个问题（光从哪来？材质是什么？哪里最吸引你？）。
- **用游戏/电影当教材**：鸣潮、黑神话、战双、你喜欢的电影——练审美同时积累行业输入。

### 5.3 参考资源（详见 `06`）
- 视频课：Krenz（透视/色彩，付费但最系统）、Proko（造型，免费+付费）、Marco Bucci（色彩与光）、Ctrl+Paint（数字绘画基础）。
- 书（选读，别从头刷）：《色彩与光线》（James Gurney）、《素描的诀窍》。
- 日常：ArtStation 首页、80.lv、游戏截图、电影帧。

## 6. 图形学怎么学（只为画面服务，不刷完整门课）

- **GAMES101 只学 9 讲**：渲染管线、光栅化、着色（Blinn-Phong）、纹理映射、几何、光线追踪概念、阴影、抗锯齿、动画/模拟概念。**不要 28 小时全刷。**
- **作业只做 PA0–PA3**（旋转/光栅化/着色/BVH）：目的是面试能讲清管线，不是刷题。
- **GAMES202 选读**：阴影、PBR/IBL、全局光照、抗锯齿——每章看 1 小时，能接住术语即可。
- **学完必须映射到 UE**：学完 Blinn-Phong → 在 UE 里搭一个"高光更锐利"的材质；学完阴影 → 调 VSM 参数看变化。
- **不要陷入数学推导**：先理解"它在解决什么问题"，公式能看懂多少算多少。

## 7. Shader / 材质怎么学

```
阶段 1：材质编辑器（节点）
  · 母材质 / 材质实例 / 参数暴露
  · 常用节点：Lerp、Multiply、Add、TexCoord、Noise、Fresnel、WorldPosition、VertexNormal
  · 练 6–8 个材质球（金属/布料/皮肤/玻璃/湿地面/自发光）

阶段 2：材质函数与复用
  · 把常用逻辑封装成 Material Function
  · 做可调参数面板（美术能自己调）

阶段 3：Custom Node / HLSL
  · 先写 UV 动画、溶解、扫描线、三平面映射
  · 学会看编译错误、优化节点数量
  · 把 HLSL 包进材质函数，配参数

阶段 4：后处理材质
  · 描边、暗角、色差、自定义 Bloom
```

**每个 Shader 的交付物**：效果 GIF + 节点截图 + 参数说明（3 行）+ 性能备注（大概多贵）。

## 8. Blender / DCC 怎么学（够用就好）

- **优先级**：建模基础（blockout/硬表面）> UV > 贴图 > 绑定/动画认知 > 脚本。
- **不追求雕刻大神**：TA 的 DCC 目标是"能把资产做出来、能导入引擎、能写脚本处理它"。
- **建模练习**：每周 1 个小道具（1–2 小时），不要一上来做角色。
- **脚本路线**：批量重命名 → 批量导出 → 资产检查（三角面/贴图尺寸/命名/UV）→ UI 面板插件。
- **Maya/Houdini 只做认知**：知道它们在公司管线里干什么、能看懂界面即可，不要求精通。
- **导出规范**：统一单位、缩放、轴向；UE 导入后检查缩放/材质槽/法线。

## 9. 教程使用规则（防"教程地狱"）

1. **一次只跟一门课**（同一技能线），学完再开下一门。
2. **1.25–1.5 倍速**，只看到"能动手"就暂停。
3. **30% 看 / 70% 做**：每看 10 分钟，至少做 30 分钟。
4. **必须关教程复现一次**（闭环第 ③ 步）。
5. **只学当前项目需要的**：项目要打光就学打光，不要"顺手把动画也学了"。
6. **不囤课**：收藏 ≠ 学会；看到好课先记进 `06` 的"待学清单"，当前项目结束后再说。
7. **记录每门课的产出**：学完没产出 = 没学。

## 10. 笔记与知识管理

### 10.1 三段式笔记（每个知识点 3–5 行）
```
【原理】它是什么、解决什么问题（一句话）
【参数】关键参数/节点/快捷键（列表）
【证据】截图 + 踩坑 + 什么时候会坏
```

### 10.2 笔记放哪
- 短期：`D:\TA_Workspace\06_Docs\notes\`（Markdown，按主题分文件）。
- 长期/公开：博客（你已有 `blog/Firefly`）+ B站专栏/知乎。
- 术语卡：本文 §12 的术语表，遇到新的就补一行。

### 10.3 每周整理（周日 15 分钟）
- 把本周 3 段式笔记合并成 1 篇周记/拆解（发不发都行）。
- 删掉"看了但没用"的收藏；把真正要用的资源移到 `06` 的清单。
- 给下周留 1 个"必须理解"的问题。

## 11. 怎么用 AI（DSH / 豆包 / ChatGPT）学得更快

**角色分工**：AI 是教练 + 项目经理 + 答疑，不是代做工具。

| 场景 | 怎么问 | 不要怎么问 |
| --- | --- | --- |
| 卡住 | 3 行：我在做什么 / 现象 / 试过什么 → 要 1 个提示 | "帮我写完这个 Shader" |
| 理解检查 | "我刚看完 XX，我的理解是……请只指出错误，最多 3 条" | "帮我总结一下 XX" |
| 出题 | "按 XX 出 5 道题，先别给答案" | "直接告诉我答案" |
| 调试 | "先给我 1 个提示，不行再给第 2 个" | 一上来要完整代码 |
| 面试 | "按库洛美术 TA 面我 5 个问题，逐题打分" | — |
| 计划 | 周日把数据丢给 AI，让它改下周计划 | 每天让 AI 重排计划 |

**铁律**：作品集的主体必须自己动手；面试官一追问就露馅的事，不要外包。

## 12. 术语速查（零基础先混个脸熟，学到哪查到哪）

| 术语 | 一句话解释 | 在哪学 |
| --- | --- | --- |
| 渲染管线 | 从 3D 数据到屏幕像素的一整条流水线 | GAMES101 L1–2 |
| 光栅化 | 把三角形变成像素的过程 | GAMES101 L5–6 |
| 着色 / Shading | 计算每个像素颜色的过程 | GAMES101 L7–8 |
| PBR | 基于物理的渲染：金属度/粗糙度/法线等参数化材质 | UE 材质文档 |
| Albedo / BaseColor | 材质的基础颜色（不含光照） | UE 材质 |
| Metallic / Roughness | 金属度 / 粗糙度，PBR 两个核心参数 | UE 材质 |
| Normal Map | 法线贴图，用颜色伪造表面凹凸细节 | UE 材质 |
| UV | 3D 表面展开到 2D 贴图的坐标 | Blender UV |
| Texel | 纹理上的一个像素 | GAMES101 L9 |
| Mipmap | 纹理的多级缩小版本，远处自动用低清 | GAMES101 L9 |
| Draw Call | CPU 向 GPU 提交一次绘制命令，越少越好 | 性能优化 |
| LOD | 细节层级：远处用低模 | UE/Blender |
| Nanite | UE5 虚拟几何体，高模不用手动减面 | UE5 文档 |
| Lumen | UE5 实时全局光照 + 反射系统 | UE5 文档 |
| 全局光照 (GI) | 光线在物体间多次反弹的间接光照 | GAMES101 L13+ / GAMES202 |
| 阴影贴图 / VSM | 实时阴影技术；VSM = 虚拟阴影贴图 | GAMES202 / UE5 |
| 后处理 | 画面渲染完后加的效果（Bloom/景深/调色/暗角） | UE PostProcess |
| Bloom | 高光溢出/辉光 | UE PostProcess |
| Tone Mapping | 把高动态范围压到屏幕范围，决定画面"灰/透" | UE 色彩管理 |
| 抗锯齿 (AA) | 消除边缘锯齿（TAA/TSR/MSAA） | GAMES101 / UE |
| Sequencer | UE 的镜头/动画时间轴工具 | UE 官方 |
| Movie Render Queue (MRQ) | UE 高质量离线渲染出图/出片 | UE 官方 |
| Niagara | UE 粒子/特效系统 | UE 官方 |

## 14. 五个常见误区

1. **"先把基础学完再做作品"** → 永远做不出作品。正确：边做边补，项目驱动。
2. **"教程看完 = 学会"** → 看完只是"见过"。正确：关教程复现 + 变体。
3. **"美术基础不重要，我是技术向"** → 程序向 TA 也要能判断画面。正确：每天 10–15 分钟拉片/看图，长期。
4. **"作品越多越好"** → 3 件精品 > 10 件练习。正确：少而精，每件配 Breakdown。
5. **"投得越多机会越大"** → 零基础作品投头部项目只会消耗自信。正确：先够到线，再投。
