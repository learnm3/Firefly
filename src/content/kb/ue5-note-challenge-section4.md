## 一句话理解

概念没真懂时，代码写不出来——先练习"**把概念讲给别人听**"：能讲清楚 = 真懂；讲不清 = 回去补课。

## 四步做法

1. **选题**：指针 / 继承 / 函数重载等"初学常卡"的概念（自己卡过的优先）。
2. **自讲**：用自己的话写解释——它是什么、为什么重要、能解决什么问题。
3. **发布**：贴到课程社区频道。
4. **纠错**：读别人的帖子 → 找常见误解 → 用"这也是个常见误区，我的理解是……"的方式给反馈，**别只说人错**。

## 检查清单

- [ ] 解释里没有照抄定义，能举出自己的例子？
- [ ] 能说出"没有它/换成别的方式会怎样"？
- [ ] 读他人帖子时能指出 1 个常见误解？
- [ ] 反馈语气是建设性的？

## 我的用法准则

写学习笔记前先自己默讲一遍：**讲不出来的点，就是笔记里要重点写的点。** 这条也直接适用于博客里的"学习笔记"文章。
