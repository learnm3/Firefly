## 发生了什么

软件工程大二，目标库洛游戏客户端开发实习。经历了一次真实的**引擎选择探索**：中途尝试过 Unity/C#（学完 C# 数据结构与 OOP，留下本知识库里的 C# 笔记），经过对比后**最终确认专注 UE5/C++**。

## 为什么最终选 UE5

1. **库洛核心项目是 UE5**：《鸣潮》用 UE5 开发，UE5 客户端岗是库洛主力需求。
2. **已有更深积累**：200 集 UE5 C++ 教程已到 49 集，有 Character/武器/IK 深度笔记。
3. **技术深度契合**：UE5 的 C++ 体系（反射/GC/框架）对客户端面试友好。
4. **探索不白费**：Unity/C# 的学习让引擎通用概念（组件化/物理/渲染/数据结构）更完整。

## 决策复盘

| 维度 | UE5（最终选择） | Unity（尝试过） |
| --- | --- | --- |
| 库洛需求 | 鸣潮（主力 UE5） | 战双（Unity） |
| 我的基础 | 教程到 49 集 + 深度笔记 | C# 从零起步 |
| 技术深度 | 更有积累，易讲透 | 需更多时间到可面试水平 |

## 当前路线

200 集 UE5 C++ 教程为主线的学习计划（[求职路线图](/roadmap/)实时同步进度）：

- 阶段一：UE5 C++ 基础（进行中，到 49 集）
- 阶段二：玩家控制与武器战斗（3C + 战斗）
- 阶段三：AI 与战斗进阶
- 阶段四：动画进阶 + Boss 战毕业项目
- 阶段五：求职冲刺与投递

## 复盘沉淀

- **引擎是工具不是信仰**：选型看目标公司需求与自身积累，但选完要**聚焦做深**。
- **探索本身有价值**：Unity/C# 学习留下的知识库、数据结构与 OOP 理解，是完整的技术底子。
- **别在两个引擎间摇摆**：时间最宝贵，方向确认后就持续执行。
