## 目标：不用临时集合反转一个 Queue

- 思路：取出队首元素 → 递归处理"剩下的队列" → 把取出的元素放回队尾。
- 原理：递归的**调用栈**本身就是 LIFO，最内层先返回，天然把顺序颠倒过来。

```csharp
void ReverseQueue(Queue<int> q)
{
    if (q.Count <= 1) return;      // 空或只剩一个,不用再反
    int head = q.Dequeue();        // 1. 取出队首
    ReverseQueue(q);               // 2. 递归反转剩余部分
    q.Enqueue(head);               // 3. 队首放到队尾
}
```

过程（队列 `1 2 3`）：
1. 取 `1` → 递归处理 `2 3`；
2. 递归里取 `2` → 处理 `3` → 放回 `2`，得 `3 2`；
3. 回到外层放回 `1` → `3 2 1` ✅ 反转完成。

## 复杂度与风险

- 时间 O(n)、**空间 O(n)**（递归调用栈本身占用栈内存）。
- 队列太长（几千以上）会**栈溢出**。
- 数据量大建议改用 **Stack（LIFO）迭代**：全部入栈再出栈，一样能反转且不会爆栈。

## 通用启发

- 凡"倒过来处理一组数据"，先想调用栈能否白嫖逆序；
- 深度不可控时优先显式数据结构（Stack / 手动循环）代替递归。
