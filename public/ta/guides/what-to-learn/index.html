以库洛「SUN-美术 TA 实习生」JD 为唯一靶子；用程序向 TA 的能力切入：UE5 渲染 + Shader + 性能 + 工具 + 图形学，美术只做判断。

JD → 5 条能力线（所有学习都挂在这里）

① UE5 写实渲染

职责 1 · 要求 3/8
Lumen/VSM/Nanite + 材质 + 灯光 + 后期 + MRQ，独立出图/出片。
证据：P2 写实场景 3–5 图 + 15s 视频

② Shader / 材质

要求 3
母材质 + 实例 + 材质函数；3 个 Custom Node HLSL；1 个后处理材质；会讲性能代价。
证据：P3 材质/Shader 包

③ 性能与优化

职责 2
stat/GPU/显存/DrawCall/Overdraw；一次量化优化；8GB 显存预算。
证据：一页性能卡 + 前后对比

④ 美术流程 + DCC + 脚本

要求 2/4
概念→建模→UV→贴图→引擎；Blender 基础 + Python 工具（资产检查）。
证据：P5 PipeCheck 插件 + 流程 Breakdown

⑤ 美术判断 + 文档/沟通

要求 5/7 · 职责 3
判断资源质量、讲清光影/色彩/构图；写 Breakdown/管线文档、做 5 分钟分享。
证据：技术文章 + 分享稿 + 作品集文档

⑥ 行业视野（补充）

要求 6
每周 1 次鸣潮/战双/3A 拉片或行业文章；面试会问"为什么库洛/最近在玩什么"。
证据：每周 1 条拆解

不该学（现在）

  • GAMES101 全 23 讲 + 全部 PA：28 小时，美术 TA 用不到一半；只选 10–11 讲，PA1/2 可选。
  • GAMES202 全课：面试只需接住术语；最多选 3 主题。
  • UE C++ Gameplay / 蓝图系统课 / 网络同步：你是美术 TA，不是客户端开发。
  • 算法刷题 / 后端 / 数据库：与岗位无关（学校课除外）。
  • Maya/Houdini 系统课：要求只是"一种以上 + 脚本"；Blender 主学，各 4h 认知即可。
  • 角色雕刻 / 绑定 / 动画 / 毛发 / 布料模拟：招聘不要求手搓角色；作品集用 MetaHuman/授权资产。
  • 纯绘画 / 素描 / 厚涂长期课：程序向 TA 只需"判断"；每天 10–15 分钟拉片，速写可选。
  • Unity / 3ds Max / ZBrush / C4D / 其他引擎：分散精力，UE 一条线打穿。
  • 影视后期合成全流程 / DaVinci 高级调色：只需基础出片，不是剪辑师。
  • 4K/8K、Path Tracer 动画、超高精度渲染：8GB 显存 + 1080p 主战场；路径追踪只出静帧。
  • Substrate / 实验性渲染 / PCG 大世界（过早）：稳定优先，先玩熟 Lumen/VSM/Nanite。
  • 付费英文大师课 / 长课囤积：现阶段中文免费资源足够；卡住再买专项。
  • 作品集堆数量 / 先学完再做 / 收藏教程：3 件精品 + 技术证据 > 10 件练习。
  • 硬件升级 / 4K 显示器：4070 8GB + 32GB 够用，有闲钱再说。

判断"该不该学"的 4 个问题

1. 对应 JD 哪一条？
职责 1/2/3；要求 2/3/4/5/6/7/8。对不上就不学。
2. 产出什么证据？
图/GIF/代码/报告/文档。没有证据就不算学。
3. 面试能讲 3 分钟吗？
讲不清 = 没懂；先写 3 行再继续。
4. 不做会挡住下一个作品吗？
不会 → 延后；会 → 立刻做。
