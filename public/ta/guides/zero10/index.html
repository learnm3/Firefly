10 天安排

D1

UE5 界面 + 移动视角 + 放物体

40 分钟 · 只看前 2–3 集
打开 P2_NeonStreet.uproject；学鼠标左键选中、右键+WASD 移动、F 聚焦；放 1 Plane + 3 Cube。
B站打开
产出：F9 截图 → 05_Renders\零基础\Day1_三个方块.png
D2

材质第一课：颜色 / 粗糙度 / 金属度

40 分钟
新建 M_Basic；BaseColor 改色、Roughness 0.2/0.5/0.8、Metallic 0/1；做 3 个材质实例赋给 3 个 Cube。
B站打开
产出：3 张材质球截图 → 05_Renders\零基础\Day2_*；1 行笔记：粗糙度/金属度改了什么
D3

灯光第一课：主光 + 天光 + 3 个角度

40 分钟
放 DirectionalLight + SkyLight + SkyAtmosphere；同一机位换 3 个主光角度/强度，各截 1 张。
B站打开
产出：Day3_灯光_01/02/03.png；观察阴影方向、明暗对比、天光补色
D4

相机与截图

40 分钟
Place Actors → Camera Actor，调机位；视口左上角切到相机（Pilot）；学三分法/前景中景背景；F9 出 1920×1080。
产出：05_Renders\零基础\Day4_相机成图.png；面板记录 Day4
D5

后期与曝光：-1.0 vs +0.5

40 分钟
放 PostProcessVolume（勾 Infinite Extent）；Exposure Compensation 设 -1.0 截一张、+0.5 截一张。
B站打开
产出：Day5_曝光_-1.png / Day5_曝光_+0.5.png；1 行笔记：哪张更适合你的场景，为什么
D6

搭一个 5 物件的小场景

60 分钟
用 2 Box + 2 Cylinder + 1 Plane 摆出前后层次；给 3 个材质；按 D3/D5 打光 + 曝光；截白模和成图各 1 张。
B站打开
产出：Day6_白模.png + Day6_成图.png
D7

复盘 + 发布

30 分钟
选 1 张最好的图；写 3 行（做了什么/卡在哪/下周先学什么）；发 1 条 B站动态或朋友圈；面板勾 D1。
产出：3 行笔记 + 1 条公开动态 + 面板 D1
D8

Blender 界面 + 建一个简单道具

50 分钟
只看 Blender 入门课的"界面/移动/建模基础"3–5 集；做一个箱子/灯柱/杯子；学会 G/R/S/Tab/E。
B站打开
产出：1 个 `.blend` 道具文件（放 01_Learning 下）
D9

Blender → UE 管线

50 分钟
导出 FBX（Apply Scalings: FBX All，-Z Forward / Y Up）→ 导入 UE；检查缩放/法线/材质槽/UV；赋材质。
B站打开
产出：Day9_导入UE.png + 3 条踩坑
D10

组合 + 第二张成图

50 分钟
把 D9 道具放进 D6 场景；调一次灯光/曝光；F9 出第二张成图；写 3 行复盘；面板勾 D2。
产出：Day10_成图2.png + 3 行笔记 + 面板 D2

每天结束记 3 行（本地保存）
