任务步骤（跟着做）

1

打开地图 / 搭一个最小测试场景

2–5 分钟
在 UE 内容浏览器双击 Content/Maps/L_NeonStreet；如果场景是空的，先放：3 个 Cube + 1 个 Plane + DirectionalLight + SkyLight + PostProcessVolume。
  • Ground：Plane 放大 10 倍，材质先不管（默认灰模即可）。
  • 3 个 Cube：一个金属感（Roughness 0.2）、一个粗糙（0.8）、一个做对比。
  • PostProcessVolume 勾选 Infinite Extent (Unbound)，否则影响不到整个场景。
预期：视口里能看到地面 + 3 个方块 + 有明显方向的光。
2

截一张基线图

3–5 分钟
调整好一个能看全场景的机位 → 按 F9 高分辨率截图（或 MRQ 单帧）→ 存到 E:\TA_Workspace\05_Renders\P2_基线\00_baseline.png。
  • 截图前先保存工程（Ctrl+S）。
  • 记录当前参数：主光角度/强度、曝光补偿、Lumen 开关（后面复盘用）。
预期：一张能当"改造前"的图，后面和调完的图并排对比。
3

曝光对比：-1.0 vs +0.5

8–10 分钟
选中 PostProcessVolume → Details 搜索 Exposure → Exposure Compensation 设 -1.0，截一张；再设 +0.5，截一张。
  • 保存为 01_exposure_-1.png 和 02_exposure_+0.5.png。
  • 如果画面完全没变化：检查项目设置里 Auto Exposure 已关、PPV 是否 Unbound、是否在 PPV 范围内。
  • 观察：亮部细节丢了没有？暗部死黑了没有？哪一版更接近你想要的"电影感"？
预期：两张图亮度明显不同，且你能说出"哪个更适合夜景霓虹"。
4

主光色温对比：3200K vs 6500K

8–10 分钟
选中 DirectionalLight → Details 搜索 Temperature → 勾选 Use Temperature，设 3200K 截一张，设 6500K 截一张。
  • 保存为 03_temp_3200K.png 和 04_temp_6500K.png。
  • 顺手把主光角度转 20–30 度，再截一张，观察阴影方向变化。
  • 思考：如果场景是霓虹夜景，主光偏暖还是偏冷？和霓虹的冷色怎么形成冷暖对比？
预期：能一眼看出暖/冷差异，并能解释"色温对比"在画面里的作用。
5

写 3 行笔记（面试能讲的技术因果）

5 分钟
用下面的输入框写 3 行，点「保存笔记」；也可以复制到 E:\TA_Workspace\06_Docs\notes\p2_lighting_log.md。
验收：3 行里至少有 1 行能解释"为什么"，而不是只写"变亮了/变暗了"。

更省事的做法：UE 学习助手（可选）

我在项目里放了一个 Python 小工具（v0.1），可以一键完成"搭测试场景 / 改曝光 / 改色温 / 截图 / 记笔记 / 打开本页"。

用法（UE 打开时）：Output Log → 左下角切到 Python，粘贴：

import sys; sys.path.append(r"E:/TA_Workspace/02_Portfolio/P2_NeonStreet/Content/Python"); import ta_guide; ta_guide.help()

然后按需执行：

ta_guide.setup_lighting_scene()   # 搭 3 Cube + Plane + 灯光 + PPV（空场景时用）
ta_guide.exposure(-1)             # 曝光补偿 -1.0
ta_guide.exposure(0.5)            # 曝光补偿 +0.5
ta_guide.temperature(3200)        # 主光色温 3200K
ta_guide.temperature(6500)        # 主光色温 6500K
ta_guide.shot("01_exposure_-1")   # 自动截图到 05_Renders\P2_基线
ta_guide.log_note("曝光 -1.0：暗部更黑，霓虹更突出")  # 追加到笔记
ta_guide.open_guide()             # 打开本页

如果报错：把 Output Log 里的红字截图发我，我来修（v0.1 以"能跑"为目标）。

不要踩的坑

  • PPV 没变化：先勾 Infinite Extent (Unbound)；再检查项目设置 Auto Exposure 是否关。
  • 截图没存到指定目录：F9 默认存到 Saved/Screenshots/WindowsEditor，用工具里的 shot() 会自动帮你复制到 05_Renders。
  • 改完没保存：每完成一步 Ctrl+S；UE 崩溃时未保存会丢。
  • 视频看太多、动手太少：每个视频最多看 10 分钟就必须暂停动手；看完整套 ≠ 学会。
  • 只记"变亮/变暗"：笔记要写"为什么"，这是面试官会追问的点。
